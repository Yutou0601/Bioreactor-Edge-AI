### I. Introduction — ✅可寫
- 動機：生物氣體升級（CO₂→CH₄）、轉換效率由生物氣體利用決定
- 缺口：壓力＝物理＋生物之**總和**；二氧化碳／甲烷感測器不可信（僅壓力/ORP/pH）
- 本文貢獻（三點）：
  1. 邊緣多訊號氣體利用**預測**模型（$R^2\approx0.99$）
  2. **證明**穩態下生物速率結構不可辨識（反證）
  3. **兩條分離路徑**設計（多訊號化學計量 + 循環時間 kLa）
- 圖：fig1（系統與訊號，當引言插圖）

### II. Related Work — ✅可寫
- kLa 質傳量測（gassing-out）、厭氧消化動力學模型
- 可辨識性：profile likelihood（Raue 2009）、結構可辨識性

- 時序曲線分群：k-Shape、DTW shapelets（備選，可略）
- 定位：本文＝**知識驅動 + 多訊號 + 可辨識性意識**，非黑箱

### III. System & Data Platform — ✅可寫
- 硬體：Jetson Orin Nano 邊緣端 + FastAPI + Vue3；每分鐘一筆
- 微正壓循環運作：進氣 1.2 → 下降 → 自動補氣（弛豫振盪）
- **可信訊號界定**：壓力×2、ORP、pH；二氧化碳/甲烷僅參考（99.98% 拖尾）
- **資料管線工程（方法論貢獻）**：標籤格式解析、記錄中斷分段（GAP 門檻）、下降段谷底判定 → 使實測資料可信可分析
- 圖：fig1（軌跡＋補氣/谷底/中斷標記）

### IV. Methods — ✅可寫（數學全定）
1. **知識驅動質傳模型**：$P(t)=P_{eq}+(P_0-P_{eq})e^{-k_{La}t}$；每循環抽 $k_{La}$、$P_{eq}'$
2. **不可辨識性定理**：$\frac{dP}{dt}=-k_{La}(P-P_{eq})-r_b=-k_{La}(P-P_{eq}')$，$P_{eq}'=P_{eq}-r_b/k_{La}$；多對一 → $r_b$ 不可辨識（附證明）
3. **多訊號探針**：ORP（Nernst，氫氣）、pH（碳酸平衡，$[\text{CO}_2]\propto10^{-pH}$）
4. **兩條分離路徑**：
   - 多訊號化學計量（$\text{CO}_2:\text{H}_2=1:4$）
   - 循環時間 kLa 槓桿（$P_{eq}'$–$1/k_{La}$ 直線，截距 $P_{eq}$、斜率 $-r_b$）
5. **統計**：混合／叢集穩健 SE、LOO-CV、**置換檢定**
- 圖：**fig14**（①不可辨識 ②解方）、fig8（擬合示例）
