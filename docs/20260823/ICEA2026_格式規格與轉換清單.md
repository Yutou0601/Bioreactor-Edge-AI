## 三、必填項目

- **CCS Concepts**：自 2012 ACM CCS 樹選取，用 https://dl.acm.org/ccs
  產生程式碼後貼入。建議：
  - 500　Information systems → Information systems applications → Data mining
  - 300　Computing methodologies → Modeling and simulation →
    Model development and analysis → Model verification and validation
  - 300　Mathematics of computing → Probability and statistics →
    Statistical paradigms → Time series analysis
  - 100　Applied computing → Physical sciences and engineering
- **Keywords**：自訂，**分號分隔**。現有五個沿用即可
  （Process data mining; Practical identifiability; Anaerobic digestion;
  Quantized sensing; Biomethanation）
- **參考文獻**：ACM Reference format，編號、**依字母排序**、9 pt、
  右側不對齊（ragged right）、超連結不加底線

## 四、CMT 主題勾選

CFP 主題共 17 項。建議勾 **Data Mining**（主）、**Cloud/Edge Computing**、
**Industrial Internet**。

⚠ **不勾 Machine Learning／Deep Learning**——本文未訓練任何模型，
勾選會被指派至 ML 審稿人，以其標準檢視反而不利。

## 五、LaTeX 轉換清單

目前 `paper/main.tex` 為 `\documentclass[runningheads]{llncs}`。

**建議用 `\documentclass[sigconf]{acmart}`。** 那份 Word 模板對應的
LaTeX 是舊版 `sig-alternate.cls`，ACM 已於 2017 年停用、TeX Live 與
Overleaf 均不再收錄；且論文集若進 ACM DL，最終仍須用 `acmart`。

| 要動的 | 作法 |
|---|---|
| 文件類別 | `llncs` → `acmart[sigconf]`；刪 `[runningheads]` |
| 套件 | 刪 `amsmath`、`hyperref`（acmart 已載，重複會報錯） |
| 作者 | `\inst{}`＋`\institute{}` → 每人一組 `\author`／`\affiliation`／`\email` |
| running head | 刪 `\titlerunning`、`\authorrunning`（ACM 不要頁首） |
| 關鍵字 | `\and` → 分號 |
| CCS | 新增 `CCSXML` 區塊與 `\ccsdesc` |
| 章節 | 需編號（ACM 要求），LNCS 原本也有 |
| 圖 | 七張皆 `width=\textwidth`；建議先全改 `figure*` 跨欄，編出來再收 |
| 演算法 | `algorithm` 與 acmart 偶有衝突（acmart 內載 `float`），必要時改 `algorithm2e` |
| 參考文獻 | 改 ACM Reference format，依字母排序 |
| 自訂巨集 | `\pu`／`\ratu`／`\rb`／`\rbh`／`\kh` 原封不動 |

⚠ **本機無 LaTeX toolchain**（見 `main.tex` 第 12 行）。轉換後務必於
Overleaf 編譯驗證，範本搜尋「ACM Conference Proceedings Primary
Article Template」。

## 六、頁數影響：由不足變寬裕

| | 版心面積 | 內文字級 |
|---|---|---|
| LNCS | 122 × 193 mm ≈ 36.5 in² | 10 pt |
| ACM | 178 × 235 mm ≈ 64.8 in² | 9 pt |

每頁容量約 1.77 倍再加字級小一級。現行 10.4 頁（LNCS）轉換後估 7–9 頁。

**2026-08-23 Word 實測：9 頁**（`ICEA2026_Li_et_al_ACM.docx`）。
推算值為 7.3 頁，差額 1.7 頁全為**分頁留白**——八個跨欄浮動體各夾在
連續分節符之間，任一個塞不進當前頁即整塊推至次頁。此與
`docx_page_count_is_gaps` 所記之教訓一致：留白才是頁數主因。

**10 頁上限不再是威脅**，先前為壓頁數所做的取捨可以放寬，
包括「為何不加裝第二支儀器」該段（原估 12 mm）。
