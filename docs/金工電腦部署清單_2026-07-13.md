# 金工電腦部署清單（2026-07-13 上線用）

前提：金工電腦平常不連網，7/13 當天暫時接網路線裝完東西後可以拔掉；作業系統 Windows；不確定有無 GPU（本清單一律假設沒有，裝 CPU 版 PyTorch，模型很小不需要 GPU）。以下每個步驟都已經在同規格（Windows）的乾淨環境上實測過。

## 1. 確認 Python 版本

```powershell
python --version
```

需要 Python 3.9 以上（專案在 3.10~3.14 都實測過可以動）。若沒有 Python，需先安裝。

## 2. 取得專案程式碼

用隨身碟複製整個 `Bioreactor-Edge-AI` 資料夾過去（含 `edge_backend/`），或如果金工電腦這時候有連網，直接 `git clone`。

## 3. 建立虛擬環境（建議，避免污染系統 Python）

```powershell
cd Bioreactor-Edge-AI\edge_backend
python -m venv venv
venv\Scripts\activate
```

## 4. 安裝 CPU 版 PyTorch（先裝這個，避免 pip 自動抓到很大包的 CUDA 版）

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

## 5. 安裝其餘依賴套件

```powershell
pip install -r requirements.txt
```

**已知修復**：`requirements.txt` 原本把 `numpy`/`pandas`/`scikit-learn` 版本釘死（`==`），在新版 Python 上會因為抓不到對應 wheel、退回原始碼編譯失敗（今天在這台開發機的 Python 3.14 上實際踩到這個問題）。已經改成下限版本（`>=`），這個問題已經修好，直接照上面指令裝即可，不需要額外處理。

## 6. 確認安裝成功

```powershell
python -c "import torch, numpy, pandas, sklearn, fastapi; print('OK')"
```

應該印出 `OK`，沒有任何 Traceback。

## 7. 裝完後可以拔網路線了

後面的操作都不需要網路。

## 8. 確認主程式與資料管線能跑

```powershell
python -c "from data_pipeline.loader import load_all_data; df = load_all_data('data/*.csv'); print(len(df), '筆')"
```

若 `data/` 資料夾裡還沒有資料（新硬體剛上線、還沒開始收集），這步會報「找不到任何 CSV 檔案」，屬正常現象，等新資料開始寫入 `edge_backend/data/` 後再跑。

## 9. 啟動即時後端（USB 感測器 + API）

```powershell
python main.py
```

確認終端機印出 `[USB] 已連接 ...` 或類似訊息（若接了感測器），以及 uvicorn 啟動在 `0.0.0.0:8000` 的訊息。

## 10. （之後）跑每分鐘分析

累積到新資料後：

```powershell
python ch4_peak_analysis.py --granularity minute --host-tag jinggong-pc
```

`--host-tag` 記得指定成能辨識這台機器的名稱（例如 `jinggong-pc`），之後才能跟 Jetson 端的結果（`--host-tag jetson`）對照比較。
