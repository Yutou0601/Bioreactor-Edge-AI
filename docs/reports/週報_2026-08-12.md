#### 一、簡併判讀由「假設函數形式」改為「反解依賴強度」

前次週期建立的配對基準中，B2（生物速率隨鬆弛常數上升）之斜率係由**實測的
(r̂_b, k̂) 配對迴歸取得**，而 ρ(r̂_b, k̂) 正是待解釋之量；以被解釋量所導出之
參數回代為真值，相關係數必然偏高，故 B2 原得之 ρ = 0.797 不構成證據。

本週改以間接推論之標準作法處理：將真值參數化為冪次形式
r_b(k) = r_b⁰ · (k/k_med)^β，掃描 β 並於每個 β 執行完整配對管線，
取得校準曲線 ρ(β)（`edge_backend/degeneracy_invert.py`）。

採冪次形式之理由有二：其一，r_b 恆為正，可避免原線性 log k 形式導出負值
（生物製造壓力）之非物理結果；其二，中位數對任意 β 均等於 r_b⁰，
不同 β 之「投入真值中位數」可直接比較，偏誤方具意義。

| β | ρ 均值 | ρ 標準差 |
|---|---|---|
| 0.00（恆定真值） | 0.278 | 0.056 |
| 0.30 | 0.724 | 0.033 |
| 0.80 | 0.760 | 0.030 |
| 實測 | **0.831** | — |

恆定真值僅產生 ρ = 0.278，與實測相差約十個標準差，**恆定生物速率之假設
被排除**。β 介於 0.20 至 0.80 者於校準散布內可重現實測相關，此集合為
後續修正之依據。

#### 二、估計偏誤之量化與修正，生物速率定版

校準曲線之用途不應止於報告偏誤，而應據以修正估計值。於相容集合內，
估計量對聚合中位數之高估為 +5.2 % 至 +14.0 %；同期計算之篩選效應
（曲率門檻偏好高 k 循環）僅佔 −0.7 % 至 −3.9 %，不足以解釋該偏誤，
故其餘部分為估計器本身之偏誤（`edge_backend/rb_corrected.py`）。

反解後之定版結果：

> **r_b = 0.0107 kg/cm²/hr**，相對未修正之 0.0117 修正 **−9.1 %**

容差取 2.0 σ 時相容集合僅餘 β = 0.40 / 0.50 / 0.65 三點，精度看似 ±1.5 %；
惟 β = 0.20 / 0.25 / 0.80 係以 2.1–2.4 σ 落選，門檻略調集合即改變，
該精度係網格運氣而非方法能力，故改採 2.5 σ，相容集合 β ∈ [0.20, 0.80]。

#### 三、不確定度之分項合成

前項之 ±4.0 % 為跨相容真值族之散布，不含抽樣誤差，非信賴區間。
本週另以 20 000 次拔靴法取得中位數之抽樣誤差，並以蒙地卡羅合成
（修正為除法運算，不可逕用誤差傳遞加總）：

| 來源 | 大小 | 性質 |
|---|---|---|
| 抽樣誤差 | ± 2.8 % | 拔靴法，301 個循環；**隨紀錄延長而收斂** |
| 系統誤差 | ± 4.0 % | 跨相容真值族；**不隨樣本數改變** |
| 合成 | **± 7.6 %** | 95 % 區間 [0.0100, 0.0116] kg/cm²/hr |

分項報告之理由為兩者可改善性不同：延長量測僅能壓縮前者，欲收窄後者
須取得 r_b(k) 之形式，單一壓力通道無法提供。

#### 七、交付物產生流程之缺陷修復與稽核工具

本週於成品中查出並修復之缺陷：

| 缺陷 | 症狀 | 成因 |
|---|---|---|
| 希臘字母未列入巨集表 | β 完全消失，`$\beta=0.30$` 印為「=0.30」 | 「刪除未知指令」規則靜默吞除 |
| 破折號規則順序 | `---` 印為「–-」 | 僅處理 `--`，長破折號被截 |
| 上下標無條件轉 Unicode | `k_{med}` 印為 kₘₑd（m、e 為真下標，d 為正常字級） | Unicode 下標集合不完整 |
| 單位排法不一致 | 全文並存 Unicode `²` 八處與真上標六處 | 內文、公式、摘要三條路徑各自展開 |
| 交叉引用未解析 | 章節引用印出 `sec:endpoint` 字面 | 節號為手寫字典，且僅收 `\section` 標籤 |
| 圖號錯位 | 內文「Fig. 5」對應圖說「Fig. 4」 | 非貪婪比對跨越環境邊界，演算法列表吃到下一張圖之標籤 |
| 書目結尾殘留 | 末筆文獻後印出「thebibliography document」 | `\bibitem` 終止條件含檔尾 |
| 土耳其字母未對應 | 書目印出 `Y\"orüklü`、`Koroglu` | 巨集表僅有 ü，缺 ö 與 ğ |

以上多數源於**內文與公式兩條展開路徑各自維護**，補規則時易顧此失彼。
為此建置 `audit.py`，自症狀反向偵測（孤立等號、空括號、混高下標、
破折號殘體），可查出既有稽核工具無法發現之「符號被吞除」類缺陷——
原稽核僅檢查殘留標記，β 消失時仍判定通過。

另建置 `layout.py` 版面模擬器，區分「內容高度」與「分頁留白」。
實測顯示超頁主因為留白而非內容：11.5 頁時正文僅 9.7 頁，留白達 1.0 頁，
係 .docx 無浮動圖、圖片塞不下即整塊推至次頁所致；有效對策為調整圖片
位置而非刪減文字。

### 補充

本週之淨效果為**主結果之不確定度較前次為大**：由「聚合中位數無偏」
改為「偏高 3–12 %，修正後 ±7.6 %」。此非退步而係更正——原「無偏」
之結論係在恆定真值假設下取得，而同一份分析已排除恆定真值，兩者不能
併存。換得者為「恆定真值被排除」一項變得紮實（約十個標準差，且不再
存在循環論證），以及一個可對外陳述的精度數字：單一量化壓力通道可將
生物速率定至約 ±8 %。
