**4. 監控電腦一鍵安裝**（ec9c10a，`deploy/monitor_oneclick.ps1`＋`.bat`）

把清單第 3.2～3.5 步做成一個檔案，雙擊即可：

| 步驟 | 做法 |
|---|---|
| 1 找專案資料夾 | 從 repo 內執行＝該 repo；從隨身碟執行＝搜尋桌面、文件、C:\、D:\，git checkout 優先 |
| 2 更新程式 | 有網路：`git pull --ff-only`（有修改先 stash）；沒網路：用隨身碟 `offline_files\` 覆蓋，舊檔先備份 |
| 3 找 CSV 資料夾 | 從 `.env`、`launcher.json`、預設路徑、全碟搜尋中選最近寫入者，30 分鐘內有寫入標 **LIVE**，詢問確認一次 |
| 4 讀通行碼 | 隨身碟 `ingest_token.txt`，沒有則沿用 `.env` |
| 5 寫 `.env` | 以 UTF-8 寫入，舊檔備份為 `.env.bak_<時間>` |
| 6 停用舊版自動啟動 | 「啟動」資料夾裡的 `BTP_monitor.bat`／`START.bat` 捷徑移到桌面備份資料夾（不刪，留作備援） |
| 7 執行安裝 | 以 UTF-8 字碼頁（`chcp 65001`）執行 `monitor_uploader_setup.bat` |
| 8 開主控台 | 開啟桌面「Bioreactor panel」 |

參數：`-DryRun` 只顯示、不做任何修改；`-Yes` 不詢問；`-Project`／`-CsvDir` 手動指定。

(1) **順帶修掉一個潛在問題**：CSV 資料夾路徑若含中文，原本的 `setup.bat` 用 cmd 寫入 `.env`
（ANSI／cp950 編碼），`config.py` 以 UTF-8 讀取會變成亂碼，上傳程式找不到資料夾；
而 `setup.bat` 自己的檢查用的是 cmd 讀到的路徑，**照樣顯示通過**。一鍵安裝改由 PowerShell 以
UTF-8 預先寫好 `.env`，再以 UTF-8 字碼頁執行 `setup.bat`。

(2) **實測**（家用電腦）：
- 預覽：分別從 repo 內與從隨身碟位置執行，八步判斷皆正確；通行碼由隨身碟讀到（32 字元）。
- 抓到並修正：專案搜尋誤選複製到桌面的離線檔案資料夾（它也有 `config.py`）→ 改為完整專案須同時有
  `edge_backend\main.py`，且 git checkout 優先；放誘餌資料夾重測通過。
- 抓到並修正：`-CsvDir` 未優先於「最近寫入」；路徑含空格時參數未加引號。
- 真正執行、CSV 路徑含中文：`.env` 為正確 UTF-8，Python 讀到且資料夾存在；`setup.bat` 第 2 步找到
  46 個 CSV，第 3 步因未接 USB 依設計停止（未上傳、未裝自動啟動）。測試後已還原家用電腦的 `.env`。
- **尚未驗證**：接上 Jetson 後的上傳與對帳（第 4～7 步）——明天現場第一次完整跑。

(3) 已知、未修：`setup.bat` 在延遲展開下會把 `[!]` 顯示成 `[]`，僅影響畫面，原本就存在。
