## 一、摘要

本報告提出三項互相支撐的結果。

**支柱一**：分離物理溶解與生物消耗的標準做法——「兩步驟表觀參數迴歸」（先各條件擬合表觀飽和壓 Peq'，再對 1/kLa 迴歸取斜率為 −rb）——在本類反應器上**嚴重偏誤**。以 rb ≡ 0 的合成資料驗證，該法回收出**假 rb = 0.0187，大於實測值 0.0143**（p=0.735），即該法在此完全無法區分訊號與假象。改用一步到位的**聯合擬合**後偏誤降低 96%，實測 **rb = 0.0110 顯著大於 0（p < 0.01）**，並得到三批的通道分解（生物份額 67% / 34% / 31%）。

**支柱二**：本反應器採閾值觸發的循環補氣，控制器每完成一次循環即免費完成一次封閉頭空弛豫實驗。量化後：**2.2 次/天**、精度隨累積循環數的**冪次為 −0.54**（獨立樣本理論值 −0.50）。冪次接近理論值是關鍵證據——代表每個循環貢獻近乎獨立的資訊，而非重複量測同一個漂移中的系統。故生產運轉本身即為一座持續累積辨識能力的平台。

**支柱三**：把上述方法放到實際邊緣裝置上量測，得到明確的算力預算。**產生一個 rb 估計只要 0.88 秒，但讓它值得信任（200 次自助校準）要 31 倍的算力**。此負載為 scipy 最佳化、GPU 完全閒置，正確的加速途徑是多核平行（實測 6.2 倍）而非 GPU。串流式循環偵測僅 0.56 μs/筆，相對 1 分鐘取樣間隔有八個數量級的餘裕，故校準可排在循環間的閒置期執行而不影響即時偵測。

三者互相支撐：支柱二解釋了支柱一為何做得到（族群式聯合估計需要許多「個體」，而閾值觸發的循環持續免費提供）；支柱三則說明這整套為何必須跑在邊緣、以及算力該怎麼分配。

### 本研究使用的功能範圍

專利範圍涵蓋三項技術主張：(1) 以流體模擬設計反應腔體形狀與結構以達成氣液混合、並模擬導電碳之置放位置；(2) 導入電發酵反應；(3) 以 H₂/CO₂ 氣體比例探討最佳反應效果。

**本研究僅使用其中的微壓循環控制功能**，界定如下（Methods 節須明確敘明）：

| 專利功能 | 本研究 |
|---|---|
| 微壓循環控制（灌至 1.2、降至 0.9 自動補氣） | **✔ 使用**——本研究之核心觀測對象 |
| H₂:CO₂ 氣體比例（本研究固定 4:1） | ✔ 使用，固定不變 |
| **電發酵（外加電位／電流）** | **✘ 未啟用**——經洪博確認「目前沒有加電」 |
| **導電碳** | **✘ 未裝設**（明日至實驗室時目視複核即可定案） |

亦即：**本研究之反應器為純粹的微壓循環系統**——無電極、無外加電位、無導電碳材。專利中的電化學強化功能均未涉及。此為最單純的組態，對訊號解讀最有利。

此界定對訊號解讀至關重要：液相若存在外加電位，ORP 電極讀值將被該電位主導，而非由 H₂ 氧化還原對決定。**本研究全程無施加電位或電流（經確認），故 ORP 為自由浮動之氧化還原電極**，其讀值反映溶液化學狀態。

資料亦與此一致：實測 ORP 於補氣時驟降 100+ mV 後自由回升、全程在 230~686 mV 間連續變動，為自由浮動電極響應溶液化學之典型行為；若受恆電位控制，讀值應被釘在受控值附近。

**論文撰寫上的意義**：此專利給予裝置正式身分，Introduction 可直接引用而不必自行論證構型的特殊性。文獻中的加壓生物甲烷化多為連續流或 trickle-bed（常見 ~2.2 bar、H₂:CO₂ = 80:20，與本機台壓力相近），而「微壓循環控制」構型受本專利保護、並非通用做法——**這正是支柱二（閾值觸發循環＝連續辨識實驗）成立的裝置前提**：連續流反應器處於穩態，無弛豫實驗可用。

## 二、支柱一：兩步驟迴歸的偏誤與校準式聯合擬合

### 2.1 問題

兩通道模型為

```
dP/dt = −kLa·(P − Peq) − rb
```

其解為單一指數，表觀飽和壓 `Peq' = Peq − rb/kLa`。既有做法（本研究先前規劃、簡報 P9/P10）是：對每個條件擬合 (kLa, Peq')，再以 Peq' 對 1/kLa 迴歸，取斜率為 −rb、截距為 Peq。

以本資料 26 個循環執行，結果看似極為漂亮：

| 量 | 值 |
|---|---|
| Peq' 對 1/kLa 的相關 | **r = −0.935** |
| p 值 | **2.6 × 10⁻¹²** |
| 表觀 rb | 0.01435 kg/cm²/hr |
| 截距 Peq | 0.8603 kg/cm² |

### 2.2 但這是假象

kLa 與 Peq 的估計誤差沿著擬合脊線**正相關**（壓力軌跡近乎直線時，兩者可互相補償）。於 Peq'–1/kLa 平面上，這個估計誤差會製造出與真實物理關係**同號**的假相關。

以參數自助法驗證：從 rb ≡ 0 的虛無模型產生合成資料（區塊自助保留原始殘差的自相關結構，block = 60 min，並重新加上 0.01 的壓力量化），再跑同一套兩步驟程序 200 次：

| | rb ≡ 0 時回收的 rb |
|---|---|
| 中位數 | **0.01872** |
| 95 百分位 | 0.02757 |
| **實測值** | **0.01435** |
| **p 值** | **0.735** |

**假 rb 比實測值還大。** 該法在此類資料上無法區分真實訊號與擬合假象，**不可用**。

### 2.3 無偏替代：一步聯合擬合

改為在單一概似下同時決定所有參數（kLa 隨批次變動、Peq 與 rb 三批共用）：

```
dP/dt = −kLa_i·(P − Peq) − rb        i = 1min, 5min, 10min
```

於同一批合成資料上驗證：

| 估計量 | rb≡0 時回收的假 rb（中位） | 偏誤 |
|---|---|---|
| 兩步驟表觀參數迴歸 | 0.01872 | — |
| **一步聯合擬合** | **0.00075** | **降低 96%** |

虛無分布的最大值為 0.00826，而實測 **rb = 0.01104 超出該最大值**，故 **p = 0.0000**。

**註**：合成資料以區塊自助保留了原始殘差的自相關結構，其中可能包含真實的生物訊號，這會使虛無分布偏大、檢定偏保守。在此前提下仍能拒絕，結論穩健。

### 2.4 校準後的參數與通道分解

| 參數 | 值 | 留一循環穩定性 |
|---|---|---|
| Peq（物理飽和壓，三批共用） | 0.9054 kg/cm² | ±0.0046（CV 0.5%） |
| **rb（生物消耗率，三批共用）** | **0.01104 kg/cm²/hr** | **±0.00029（CV 2.6%）** |
| kLa（1min） | 0.0384 /hr | — |
| kLa（5min） | 0.1489 /hr | — |
| kLa（10min） | 0.1673 /hr | — |

通道分解（以典型工作點 P = 1.05 估）：

| 批次 | 物理 kLa(P−Peq) | 生物 rb | **生物份額** |
|---|---|---|---|
| 1.1 (1min) | 0.0056 | 0.0110 | **67%** |
| 2.1 (5min) | 0.0215 | 0.0110 | **34%** |
| 3.1 (10min) | 0.0242 | 0.0110 | **31%** |

生物份額隨 τ 下降**並非生物活性下降**（rb 三批共用同一值），而是物理質傳被循環時間大幅增強所稀釋。

### 2.5 必須誠實標註的一點

M2（令 rb ≡ 0）與 M3（含 rb）的**逐循環預測**差異不顯著（26 個留出循環中 M3 較優者 15 個，Wilcoxon p = 0.468，且 50% 的改善集中於單一循環）。因為 rb 對預測誤差的貢獻很小。

故正確表述為：

> **「rb 被穩定且顯著地估計出來」**，而非「加入生物通道顯著改善預測」。

此外，排氣目測 CH₄ 達 31.64% / 34.84% / 43.04%，已獨立證實生物確實在作用；本結果提供的是該速率的**定量值**，而非其存在性的證明。

## 三、支柱二：自我辨識平台

### 3.1 主張

本反應器採閾值觸發的循環補氣（灌至 1.2 kg/cm²，壓力降至 0.9 自動補氣）。控制器每完成一次循環，即等於免費完成一次**封閉頭空弛豫實驗**——不中斷生產、不注入測試訊號、不消耗額外試劑。

對照：連續流反應器處於穩態，弛豫實驗數為零；欲辨識參數必須刻意擾動（gassing-out 需停機數小時，且只提供 kLa、不提供生物速率）。

### 3.2 三個量化指標

**指標 1 — 產出速率**

| | |
|---|---|
| 觀測期 | 12 天 |
| 完整弛豫實驗數 | 26 次 |
| **產出速率** | **2.2 次/天** |
| 單次實驗時長 | 6~15 hr |

**指標 2 — 學習曲線**（可重複抽樣自助法，60 次重複）

| 累積循環 n | 約合天數 | rb 估計 | 標準差 | CV |
|---|---|---|---|---|
| 3 | 1.4 | 0.01204 | 0.00431 | 35.8% |
| 5 | 2.3 | 0.01371 | 0.00257 | 18.8% |
| 8 | 3.7 | 0.01187 | 0.00250 | 21.1% |
| 12 | 5.5 | 0.01096 | 0.00238 | 21.7% |
| 16 | 7.4 | 0.01173 | 0.00175 | 14.9% |
| 20 | 9.2 | 0.01119 | 0.00145 | 13.0% |
| 26 | 12.0 | 0.01113 | 0.00129 | 11.6% |
| 40 | 18.5 | 0.01125 | 0.00099 | 8.8% |
| 60 | 27.7 | 0.01105 | 0.00078 | 7.1% |

> **方法註**：必須用「可重複抽樣」的自助法。若用不重複的子抽樣，n 趨近全集時標準差會被迫歸零，導致冪次擬合出 −3.48 之類的無意義值。

**指標 3 — 獨立性（關鍵證據）**

| | |
|---|---|
| 實測精度冪次 | **−0.54** |
| 獨立樣本理論值 | −0.50 |

冪次接近 −0.5 代表**每個循環貢獻近乎獨立的資訊**。若只是重複量測同一個漂移中的系統，精度會很快飽和（冪次趨近 0）。此為「平台確實在累積辨識能力」的直接證據。

### 3.3 投影

| 目標精度 | 需累積循環 | 約合連續運轉天數 |
|---|---|---|
| CV < 15% | 16 | 7.4 天 |
| CV < 10% | 34 | 15.8 天 |
| CV < 5% | 123 | 56.8 天 |

### 3.4 與邊緣運算的連結

這給了「為何需要邊緣運算」一個紮實的答案：**必須全天候在現場，才抓得到每一次補氣與每一次參數切換**。這不是為了節省頻寬，而是辨識能力的來源本身。現場網路不穩（開發機連不到 broker 即為實例）時，本地仍須持續偵測與抽取。

## 四、支柱三：邊緣算力預算

### 4.1 為何要量這個

支柱一的核心是：未校準的參數估計會產生 p=2.6×10⁻¹² 的假結果，必須以參數自助法校準才可信。但校準的算力需求遠高於估計本身——**這正是邊緣裝置的核心兩難：算力有限，但不能把未校準的參數往上送。**

量測腳本 `edge_benchmark.py` 設計為平台自動偵測、輸出 JSON，同一支可在 x86、RTX 工作站、Jetson 上執行，結果直接併表。

### 4.2 實測結果（開發筆電，Intel 14 核，Windows）

| 階段 | 數值 |
|---|---|
| S1 循環偵測（串流版） | **0.56 μs/筆** — 相對 1 分鐘取樣間隔餘裕 10⁸ 倍 |
| S1 循環偵測（批次版） | 3.85 μs/筆（5,664 筆 → 13 循環） |
| S2 每循環特徵抽取 | 3.47 ms/循環 |
| S3 聯合擬合（單次估計） | **0.88 s** |
| S4 自助校準（單核，200 次） | 約 3 分鐘 — **是估計本身的 31 倍** |
| S4b 自助校準（13 核平行） | **加速 6.2 倍** → 約 0.5 分鐘 |
| S5 局部法 vs 差分演化 | 0.78 s vs 30.8 s（**慢 39 倍**） |
| S6 峰值記憶體 | 326 MB |

### 4.3 三個部署層面的結論

**（一）校準可以排程，不必犧牲即時性。** 串流偵測 0.56 μs/筆，而循環間隔 6~15 小時；校準只需 0.5~3 分鐘，排在循環間的閒置期即可，完全不影響每分鐘的即時偵測。

**（二）此負載該配多核 CPU，不是 GPU。** 全程為 scipy 最佳化，GPU 完全未被使用。200 次自助彼此獨立（embarrassingly parallel），故隨核數近線性加速——實測 13 核得到 6.2 倍。Jetson Orin Nano 的 6 核 CPU 正好適用；配 GPU 對此負載無益。

**（三）最佳化器的選擇是可靠度取捨。** 差分演化慢 39 倍，但 10 次獨立執行全部收斂到同一解（rb 範圍寬度為 0）；局部法在 40 個隨機起點下有 **5% 收斂到 rb = 0**——那會直接翻轉結論。在無人值守的邊緣裝置上，這種靜默失敗是致命的，故 23 秒的代價值得付。

### 4.4 量測過程中修掉的三個陷阱

這些在 Jetson 上會更嚴重，記錄下來供複用：

1. **平行化一開始量出 0.8 倍（反而變慢）**。30 個任務分給 13 個行程，每個只跑 2 次，行程啟動與資料重載的開銷蓋過計算。加入暖機階段、並令任務數 ≥ 3 倍行程數後，才量到真實的 6.2 倍。
2. **Windows 讀不到記憶體**。ctypes 未設 `argtypes`，64 位元下 HANDLE 被截斷，API 靜默回傳失敗。補上 argtypes 後才取得 326 MB。
3. **Windows 沒有 `resource` 模組**。已加三層退路（resource → psutil → ctypes）。

### 4.5 待補（明天實機）

同一支腳本在 **RTX 3060 工作站**與 **Jetson Orin Nano** 上各跑一次，即可得到三層對比表：

```
python edge_benchmark.py --quick --nboot 40    # 先試跑
python edge_benchmark.py --nboot 200           # 正式
```

建議 Jetson 先用 `--quick`——差分演化在 x86 需 30 秒，ARM 上可能數分鐘。

## 五、可部署的即時預測模型

### 5.1 任務設計

支柱一的機理模型每循環才輸出一次參數。邊緣端另有一個每分鐘的需求：**預測何時需要補氣**。故設計監督式任務：

- 輸入：過去 60 分鐘的〔壓力、ORP、pH〕
- 輸出：60 分鐘後的壓力
- 切分：GroupKFold（依循環分組，5 折），測試循環完全未被看過
- 樣本：n = 9,522 個視窗，來自 26 個循環

### 5.2 結果

| 模型 | GroupKFold RMSE | 相對機理模型 |
|---|---|---|
| persistence | 0.02781 | — |
| **mechanistic（機理短期外推）** | **0.02427** | 基準 |
| linear | 0.01855 | 好 1.3 倍 |
| PINN-LSTM（加物理軟約束） | 0.00916 | 好 2.6 倍 |
| **LSTM（因果單向，可即時部署）** | **0.00900** | **好 2.7 倍** |
| Bi-LSTM（需未來，僅離線） | 0.00860 | 好 2.8 倍 |

### 5.3 三點解讀

**（一）機理模型輸了不是矛盾，是任務不同。** 用 60 分鐘視窗擬合指數再外推 60 分鐘是病態問題——時間常數為 6~25 小時，一小時的資料約束不住它，所以連線性外推都比機理擬合好。**機理模型擅長的是整個循環的參數估計（支柱一），不是局部短期預測。** 這是清楚的分工：機理＋校準每循環跑一次（慢、貴、可解釋、經校準），LSTM 每分鐘跑一次（快、準、可即時）。

**（二）因果版本幾乎不用付代價。** 可部署的單向 LSTM（0.00900）只比需要未來時間步的雙向版（0.00860）差 **4.7%**。文獻中交通預測的對應差距達 37.78%，故此應用的因果約束成本異常地低——這對邊緣部署是正面結論，也解答了先前「Bi-LSTM 無法即時推論」的疑慮：**不必糾結，單向就夠**。

**（三）物理軟約束在此無增益。** PINN-LSTM（0.00916）與純 LSTM 幾乎相同。誠實的寫法是：在本任務上物理先驗既未幫助也未損害。

### 5.4 非監督部分（誠實的負面結果）

PCA 前二主成分累積 66%；K-means++ 最佳 k=3（silhouette 0.418），但分群結果基本上只是**還原「批次」這個已知標籤**（k=3 時一致度 73%、k=4 時 88%）：1min 全在一群、10min 全在另一群、5min 被拆開。**未發現超出批次的隱藏結構**，與 2026-07-27 在另一批資料上的結論一致。此點應寫成一句驗證，不可當作貢獻。

### 5.5 三項部署決策分析（圖29）

模型固定為因果單向 LSTM（唯一可即時部署者），GroupKFold 依循環分組。

**D1 — 預測地平線：能看多遠？**

| H（分鐘） | LSTM RMSE | persistence | 優於基準 |
|---|---|---|---|
| 15 | 0.01053 | 0.01259 | 1.2× |
| 30 | 0.01137 | 0.01786 | 1.6× |
| 60 | 0.00978 | 0.02784 | 2.8× |
| 120 | 0.01465 | 0.05323 | 3.6× |
| 240 | 0.02347 | 0.09595 | 4.1× |

兩點值得注意：

1. **15~60 分鐘的 RMSE（0.0098~0.0114）幾乎等於壓力量化單位 0.01**。也就是說在這個地平線內，模型已抵達**量測解析度的下限**——限制來自感測器，不是模型。這解釋了為何 H=15 並不比 H=60 更準。
2. **相對基準的增益隨地平線單調上升**（1.2× → 4.1×）。地平線越長，naive 基準越無用、學習模型的價值越高。四小時的預測仍可用（RMSE 0.023，約為循環總壓降 0.25 的 9%）。

**D2 — 感測器消融：多裝的感測器值不值得？（最關鍵）**

| 配置 | RMSE | 相對僅壓力 |
|---|---|---|
| 僅壓力 | 0.00978 | — |
| **壓力 + ORP** | **0.00918** | **改善 6.1%** |
| 壓力 + ORP + pH | 0.00978 | +0.1%（等於沒有） |

**這與支柱一的獨立發現完全吻合**：

- **ORP 有微弱但真實的資訊**（改善 6.1%）——對應支柱一測到的「慢速漂移 +2.26 mV/hr 存在，但需累積 12 個循環才顯著」
- **pH 毫無貢獻**（加了等於沒加）——對應支柱一測到的「每循環僅 7~9 個量化階」

**兩條完全獨立的證據鏈（參數辨識 vs 監督式預測）指向同一結論**，這比任何單一分析都有說服力。硬體決策上：ORP 值得保留但需改善訊噪比；pH 在現有解析度下對兩類任務都無用。

**D3 — 循環內誤差分布：何時最不準？**

| 循環內相對位置 | RMSE |
|---|---|
| 0.07~0.27（補氣後） | 0.01043 |
| 0.27~0.42 | 0.01109（最差） |
| 0.42~0.57 | 0.00963 |
| 0.57~0.72 | 0.00944 |
| 0.72~0.93（接近谷底） | **0.00802（最佳）** |

預測在循環**前段最不準、後段最準**，誤差相差 38%。物理上合理：補氣後的快暫態（見支柱一發現的 ORP 兩時間尺度）難以預測，而後段動態緩慢平滑。部署上的意涵：**補氣後的頭一至兩小時應對預測保守**，或改以機理模型的短期外推補強。

## 六、誠實的文獻定位

已查證，兩個支柱**皆不可宣稱概念原創**：

| 概念 | 現況 | 出處 |
|---|---|---|
| 兩階段估計有偏、一步聯合擬合較優 | 族群藥動學 1980 年代以來的基礎知識；STS 可高估變異達近五倍 | [Population pharmacokinetics II: estimation methods](https://pubmed.ncbi.nlm.nih.gov/15367729/) |
| 生產設備的連續參數估計 | 石化、聚合反應器已有實作 | 製程控制文獻 |
| 加壓循環式生物甲烷化 | 已建立；文獻常用 ~2.2 bar、H₂:CO₂ = 80:20 | [Biomethanation processes: high H2 partial pressure](https://pmc.ncbi.nlm.nih.gov/articles/PMC7419211/) |
| 參數自助法建構虛無分布 | 標準統計程序 | — |
| LSTM 預測厭氧消化 | **非常成熟**；2024-25 已有 LSTM/RF vs ADM1 的直接比較 | [Machine learning vs. ADM1](https://pmc.ncbi.nlm.nih.gov/articles/PMC12874345/) |
| 因果 vs 雙向 LSTM 的即時性限制 | 已知共識：即時邊緣部署下單向為唯一可行選項 | 時序預測文獻 |
| 生產設備的連續參數估計 GPU vs CPU | 一般性議題，非本領域特有 | — |

> 本機台進氣 1.2 kg/cm² 錶壓 ≈ **2.23 bar 絕對壓**，與文獻的 ~2.2 bar 幾乎相同，故可直接引用比較，不需從零建立脈絡。

**可以宣稱的三點**：

1. **首次量化**該偏誤在物理／生物分離問題中的量級，並證明既有被提議的循環時間槓桿法因此**失效**（假 rb 大於實測值）。
2. **首次**將族群式聯合估計 + 參數自助校準用於生物反應器的物理／生物分離，取得經偏誤校準的 rb。
3. **首次量化**生物反應器的自我辨識平台特性（產出速率、學習曲線、獨立性冪次）；製程工業有此概念，但未見於生物反應器。

**支柱三與 LSTM 部分的定位**：LSTM 結果**只能當驗證，不可當貢獻**（該方法在本領域已非常成熟）。但兩個具體數字值得寫入：

- 本應用的**雙向 vs 因果差距僅 4.7%**，而文獻中交通預測的對應差距達 37.78%——故此處的因果約束成本異常地低，對邊緣部署是正面結論。
- 文獻報告「LSTM 訓練時間為 ADM1 的 141 倍」，可與本研究量到的「校準成本為估計本身的 31 倍」並列，共同支撐「**可信度與智慧都要付算力**」這個邊緣運算主軸。

定位為「方法遷移 + 揭露既有做法缺陷 + 量化新特性」，屬紮實的 incremental 貢獻。

## 七、走過的彎路（方法論記錄）

為得到上述結果，共嘗試十種途徑，其中九種失敗。此記錄對論文的 Limitations 與 Future Work 有價值，也可避免後續研究重蹈覆轍。

| # | 方法 | 結果 |
|---|---|---|
| 1 | τ 槓桿線（Peq' 對 1/kLa） | 有效相異點僅 2 個；後證實為兩步驟偏誤 |
| 2 | CH₄ 化學計量錨點 | 氣體記帳有缺口，生物份額 > 100% |
| 3 | ORP Nernst 雙驅動迴歸 | 1/3 批顯著（ORP 訊噪比不足） |
| 4 | 雙狀態氣相模型 | 參數貼邊界、份額不可辨識 |
| 5 | 直接 profile 生物份額 | 平坦（懲罰僅 0.8% / 5.0%） |
| 6 | ORP 晚期窗（去除快暫態） | 1/3 批顯著 |
| 7 | 重置特徵雙時鐘 | 加循環固定效應後 2/3 批消失 |
| 8 | 量化跳降點過程 | 1/3 批勉強（t = 2.04） |
| 9 | Hankel-DMD / HAVOK 模態分析 | 雙指數擬合崩潰（k₁ = k₂），僅一個時間尺度 |
| **10** | **校準式聯合擬合** | **★ 通過（p < 0.01）** |

### 三個反覆出現的陷阱

**（一）內生觸發**。補氣由壓力閾值觸發，故本質較慢的循環既花較久到達任一壓力、又在該壓力有較小的 |dP/dt|。此混淆會使任何跨循環比較產生假的正效應。循環長度與平均速率的相關達 r = 0.869 / 0.887 / 0.664（皆 p < 0.05）。
→ **對策**：任何跨循環估計量都必須加循環固定效應檢查。**建議將補氣改為定時觸發**，可零成本消除此混淆。

**（二）自相關**。1 分鐘取樣的資料高度自相關，F 檢定會把 4,000+ 個相關點當獨立，給出假的 p = 0。
→ **對策**：一律改用留一循環 / 留一批次交叉驗證。

**（三）邊界逃逸**。Nelder-Mead 精修若不傳入 bounds 會逃出參數框，產生 kLa = 2×10⁹、c_sat = 331 之類的無意義解。
→ **對策**：所有精修步驟一律帶入 bounds，並檢查參數是否貼邊界。

## 九、待辦

1. **補氣改為定時觸發**（改控制程式，零成本）。可消除內生性混淆，使後續所有跨循環分析變乾淨。**建議優先執行。**
2. **純 CO₂ 對照**（數小時封閉衰減，τ 維持不變）。rb ≡ 0 的實測基線，可直接驗證支柱一的校準是否正確——這是對整套方法最強的否證檢驗。
3. **改善 ORP 訊噪比**（±20 mV → ±2 mV，或取樣率提高到每 5~10 秒）。目前 ORP 的慢速漂移僅 +2.26 mV/hr，需累積 12 個循環才顯著。
4. **確認壓力計為錶壓或絕對壓**。不影響支柱一的 rb（rb 對壓力平移免疫），但影響 Peq 的絕對值解讀。
5. ~~補測邊緣端指標~~ **（已完成，見第四章）**。仍待在 **RTX 3060 工作站**與 **Jetson Orin Nano** 上各跑一次 `edge_benchmark.py`，取得三層對比表。

6. **決定 pH 感測器的去留**。兩條獨立證據（參數辨識的量化階分析、監督式預測的消融）均顯示 pH 在現有 0.01 解析度下無貢獻。若要保留，需將解析度提升至 0.001。
