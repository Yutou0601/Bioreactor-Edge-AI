# 實驗設計：暫態分離協定（CO2 物理溶解 vs 生物消耗）

| | |
|---|---|
| 日期 | 2026/07/26 |
| 提報 | 李承育 |
| 對象 | 洪博 |
| 目的 | 在現有 9 批次 DOE 之上，補入「純物理對照」與「暫態窗口」，使物理溶解與生物消耗**真正可分離** |
| 依據 | 可辨識性決定性測試（`co2_greybox_identifiability.py`）：穩態下兩通量結構上相等、分不開；分離只發生在暫態。詳見 2026-07-26 技術備忘。 |

---

## 一、為什麼現有設計分不開，這份協定補什麼

**核心限制（已用機理模型量化）**：反應槽日常運轉多處於**穩態**，此時
「溶解通量 ≡ 生物消耗通量」是同一個數，從壓力下降**無從歸因**——換任何演算法都一樣。
物理速率 kLa 在穩態資料下信賴區間 ±160%，在含**暫態**的資料下收斂到 ±0%。

**分離只需要兩樣現有設計沒有的東西**：

1. **純物理對照**：無生物活性下的純溶解，用來獨立釘死物理項（kLa、亨利飽和 C\*）。
2. **暫態窗口**：液相遠離飽和（溶解通量暫時 ≫ 生物通量）的資料，兩通量才解耦；
   生物量再以「總通量 − 已釘死的物理通量」殘差取得（沿用 2026-04-07 換液後暫態
   之分離原理：物理 48.6%／生物 51.4%，惟當時 n=1，本協定要把它做成有重複、可信）。

**好消息**：暫態是**大訊號、慢過程**（填充液相池歷時數小時），因此**不受**先前
死路3 的解析度限制（那是每小時 5 分鐘循環的**細結構**才需要 0.001 級解析度）。
本協定用現有 0.01 級壓力解析度、1 筆/分鐘即足夠。

## 二、三個設計元素

### 元素 A：純物理對照（釘死 kLa 與 C\*）—— 新增，僅需一次

在**無生物消耗**的條件下，把 CO2 打進液相，量測純溶解曲線（由快而慢趨近飽和）。
此曲線直接給出 kLa 與飽和濃度 C\*，之後主實驗的生物量即可用殘差算出。

作法二選一（**屬操作決定，待洪博定**）：

| 作法 | 原理 | 優點 | 代價 |
|---|---|---|---|
| **加甲烷菌抑制劑**（如 BES） | 專一抑制產甲烷、不改變液相性質 | 液相離子強度不變，kLa／C\* 最乾淨；不犧牲菌群 | 需確認藥劑與劑量 |
| **熱滅活 / 換新鮮無菌液** | 移除全部生物活性 | 完全無生物項 | 犧牲該批菌群、且液相性質可能改變 |

若兩者皆不便，退而用**文獻亨利常數 + 既有 `co溶入液體` 資料**（若那是同反應器量測），
代價是物理項不確定性較大、分離區間較寬。

### 元素 B：暫態窗口（分離的資訊來源）—— 從現有換液流程即可取得

每次**換液／洗管線到基準**之後，液相之溶解態 CO2 被重置、遠離飽和。其後
**第一個補氣循環**溶解驅動力最大、下降最快（歷史觀測首循環達穩態 3.38 倍），
這就是暫態窗口。**要求：換液後第一循環務必以完整逐分鐘軌跡記錄、不得中斷**
（控制台「資料記錄」需為綠燈才開始）。每個 n 水準都自帶一個換液後暫態。

### 元素 C：打亂順序 + 穿插參考（清理菌齡共線）—— 僅換排程

現行 n=1→5→10 與天數對齊，n 效應與菌齡糊在一起。改為：

- **打亂 n 執行順序**（見下表排程），使菌齡不與 n 對齊。
- **每日開頭跑一次固定參考水準 n=5**，追蹤菌群漂移曲線，供事後扣除菌齡效應。

## 三、建議排程（天數／時長屬操作決定，待洪博定）

> 下表為**結構建議**；每批實際時長依壓力由 1.2 降至 0.9 之實測速率而定
> （中位 0.0146 kg/cm²/hr → 約 20hr／批，見 2026-07-17 循環時間說明）。

| 階段 | 內容 | n | 目的 |
|---|---|---|---|
| 第 0 天 | **純物理對照**（元素 A） | — | 釘死 kLa／C\* |
| 第 1 天 | 參考 n=5 → 換液 → **n=10**（記暫態） | 5, 10 | 主實驗 + 漂移錨點 |
| 第 2 天 | 參考 n=5 → 換液 → **n=1**（記暫態） | 5, 1 | 打亂順序 |
| 第 3 天 | 參考 n=5 → 換液 → **n=5** | 5, 5 | |
| 第 4 天 | 參考 n=5 → 換液 → **n=1**（記暫態） | 5, 1 | |
| 第 5 天 | 參考 n=5 → 換液 → **n=10**（記暫態） | 5, 10 | |
| 第 6 天 | 參考 n=5 → 換液 → **n=1**（記暫態） | 5, 1 | 每水準達 3 重複 |

- 主實驗仍為 **n=1／5／10 各 3 重複**（與 07-19 定案相同），僅**順序打亂**並各自
  **保留換液後暫態**；另加**每日參考 n=5** 與**一段純物理對照**。
- 固定條件不變：H2:CO2 = 4:1、進氣至 1.2、排氣至 0.9、30°C（沿用 07-19 定案）。

## 四、每批操作步驟（現場）

1. 開控制台，確認 **Jetson 後端綠燈、資料記錄綠燈**（防止 07-22 靜默中斷重演）。
2. 洗管線至基準（CH4 9%／CO2 21%／壓力基準）。
3. **進氣前拍照並記 ORP**（菌群成熟度共變數錨點）。
4. 進氣至 1.2 → 建批次，開始時間設為進氣時刻（使首個循環判定為完整）。
5. 每時循環 n 分鐘，壓力降至 0.9 自動補氣，運轉至排氣。
6. 排氣時填入實際時刻，記錄 pH／ORP／CH4 峰值。
7. **換液後第一循環之完整軌跡務必確認有記到**（暫態窗口，分離的關鍵資料）。

## 五、量測與對應分析

| 產出資料 | 餵哪支分析 | 得到什麼 |
|---|---|---|
| 純物理對照曲線 | `co2_greybox_identifiability`（真實資料版） | kLa、C\*（釘死物理項） |
| 換液後暫態軌跡 | 同上 + 殘差法 | **物理／生物佔比 + 不確定性區間** |
| 每循環特徵 + 進氣前 ORP | `co2_covariate_association` | 平緩化是生物還是物理（關聯） |
| 排氣 CH4 峰值 + 相位特徵 | `ch4_realtime`（XGBoost+SHAP） | 特徵歸因（輔助、參考級） |

## 六、待洪博確認事項

1. **純物理對照怎麼做**：加抑制劑（BES 之類，需定藥劑與劑量）？熱滅活？或改用
   `co溶入液體`（須先確認是否同反應器、連續流）？
2. **可否犧牲一段運轉做純物理對照**（若採滅活）？或改用不犧牲菌群的抑制劑？
3. **打亂順序 + 每日參考 n=5** 可否納入排程（表三結構）？
4. **換液後暫態**：現行換液流程是否足以讓液相遠離飽和？換液後多久內開始記錄？
5. 主實驗時長／每日排程之實際天數（依現場設備連續使用時間定）。

## 七、預期產出與論文定位

- **可交付結論**：各 n 水準之「物理溶解佔比 / 生物消耗佔比」點估計 + **不確定性區間**，
  以純物理對照與換液暫態為依據，非黑箱回歸。
- **論文定位（誠實）**：不寫「我們分離了 CO2」的空泛宣稱，而寫
  **「以受控暫態與物理知情（灰箱）估計，量化生物甲烷化反應器之 CO2 生物消耗佔比及其可辨識性」**。
  此定位有前沿文獻（PINN／灰箱 gas–liquid 傳質模型）背書，且誠實反映可辨識性限制。
