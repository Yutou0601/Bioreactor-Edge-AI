## Abstract

> 15–250 words。以下 **198 words**。

Edge devices that estimate physical parameters from sensor streams face a dilemma that is rarely quantified: producing an estimate is cheap, but certifying that the estimate is not an artifact is expensive. We study this trade-off on a patented micro-pressure recirculating biomethanation reactor, where the automatic gas-refill controller turns routine production into a continuous sequence of closed-headspace relaxation experiments—2.2 identification experiments per day at zero production interruption. Using 26 such cycles across three circulation-time settings, we show that the conventional two-stage apparent-parameter regression used to separate physical dissolution from biological consumption is severely biased: on synthetic data generated with the biological rate fixed at zero, it recovers a spurious rate of 0.0187 kg cm⁻² h⁻¹, *larger* than the 0.0143 measured on real data, despite an apparent correlation of r = −0.935 (p = 2.6 × 10⁻¹²). A single-step joint estimator reduces this bias by 96%, after which the biological rate 0.0110 ± 0.0003 is significant against a parametric-bootstrap null. On-device measurements show that this certification costs roughly 200× a single estimate, is embarrassingly parallel (5.7–6.2× on multicore), and never touches the GPU.

**Keywords:** Edge computing · Parameter identification · Bootstrap calibration · Estimation bias · Biomethanation · Self-identifying systems

## 2 Related Work

> **配置：約 0.7 頁（250 字）。四小段，每段 2–3 句 + 引用。**
> **⚠ 誠實原則：本節必須主動承認方法本身非原創，把新意壓在「用法與量化」。**

**Two-stage versus joint estimation.** 兩階段估計高估變異、單步族群式估計偏誤較小，是族群藥動學自 1980 年代以來的基礎結果 [1]。本文的貢獻不在於重新發現此現象，而在於**量化它在物理／生物速率分離問題上的量級**，並指出其會使既有分離方案失效。

**Gas–liquid mass transfer in biomethanation.** 氫氣的氣液質傳為嗜氫產甲烷的限速步驟 [2,3]；加壓操作（約 2.2 bar、H₂:CO₂ = 80:20）已是既有做法 [3]。本機台壓力與文獻相近，差異在於**閾值觸發的循環運轉**而非連續流。

**Identification from routine operating data.** 以常規運轉資料進行閉迴路系統辨識在製程工業已成熟 [4]，但未見於生物反應器之質傳／生物速率分離。

**Machine learning for anaerobic digestion.** LSTM 等模型預測沼氣產量已相當成熟，2024–25 已有與 ADM1 機理模型的直接比較 [5]。本文之 LSTM 結果僅作**可部署性驗證**，不列為貢獻。

## 4 Method

> **配置：約 2.2 頁（600 字 + 3 個演算法 + 2 條公式）**

### 4.1 Two-Channel Model

封閉頭空之壓力下降來自物理溶解與生物消耗兩通道：

```
dP/dt = −k_La (P − P_eq) − r_b                                    (1)
```

其解為單一指數，表觀飽和壓為

```
P_eq' = P_eq − r_b / k_La                                          (2)
```

由式 (2)，若 k_La 隨 τ 改變而 r_b 不變，則 P_eq' 對 1/k_La 應呈直線，斜率 −r_b、截距 P_eq。這正是既有分離方案的依據，也是本文所檢驗的對象。

### 4.2 Algorithm 1: Streaming Cycle Segmentation

> **演算法框（Springer 用 typewriter font）**

```
Input : pressure stream p[t], rise threshold δ = 0.03,
        gap tolerance G = 30 min, merge window W = 20 min
Output: list of cycles (refill peak → valley)

state ← {peak, valley, in_cycle}
for each new sample p[t]:
    if t − t_prev > G:            # recording gap → close segment
        close_current_cycle(); reset(state)
    if p[t] − valley > δ:         # refill edge
        if within W of previous edge: extend current refill
        else: close_current_cycle(); start_new_cycle()
        peak ← p[t]
    else if p[t] < valley:
        valley ← p[t]             # track running minimum
emit cycle when next refill begins; decline ends at valley
```

> **三個設計決策要在正文說明理由**（各一句）：
> (a) 30 分鐘的中斷門檻——5 分鐘過嚴，會把良性短暫停頓誤判為中斷；
> (b) 20 分鐘的合併窗——補氣有時緩升十餘分鐘，否則會被切成多次；
> (c) 下降段終點取谷底而非下一次峰——否則末點落在上升邊，速率被嚴重低估。

### 4.3 Algorithm 2: Single-Step Joint Estimation

```
Input : cycles grouped by batch i ∈ {1min, 5min, 10min}
Output: θ = (k_La,1 , k_La,2 , k_La,3 , P_eq , r_b)

minimize  Σ_i Σ_{j∈cycles(i)} Σ_t [ P_ij(t) − P̂(t; k_La,i , P_eq , r_b , P_ij(0)) ]²
subject to bounds B
    stage 1: L-BFGS-B from p₀
    stage 2: Nelder-Mead refinement, WITH the same bounds B
```

> **⚠ 必須在正文點名的實作陷阱**：Nelder-Mead 精修若未帶入 bounds 會逃出參數框，產生 k_La ≈ 2 × 10⁹ 之類的無意義解。此為可重現的失敗模式，值得寫一句。
>
> **關鍵對比**：k_La 隨批次自由，但 **P_eq 與 r_b 三批共用**——這正是兩階段法所缺的約束，也是偏誤降低的來源。

### 4.4 Algorithm 3: Parametric Bootstrap Calibration

```
Input : data D, estimator Ê, B = 200
Output: null distribution of r_b under H₀ : r_b ≡ 0

θ₀ ← fit D with r_b fixed to 0
residuals ρ_ij ← P_ij − model(θ₀)
for b = 1 … B:
    for each cycle: resample ρ in blocks of 60 min   # preserve autocorrelation
                    D*_ij ← model(θ₀) + ρ*  ;  quantize to 0.01 kg cm⁻²
    r_b^(b) ← Ê(D*)
p ← # { r_b^(b) ≥ r̂_b } / B
```

> **兩個要在正文強調的設計**：
> (a) **區塊自助**保留原始殘差的自相關結構——若用逐點重抽會低估虛無分布、使檢定過度樂觀；
> (b) 合成資料**重新量化**至 0.01，確保虛無與實測面對相同的量測解析度。
> 又：殘差中可能仍含真實生物訊號，故此虛無分布偏大、檢定**偏保守**。

## 5 Results

> **配置：約 2.8 頁（700 字 + 5 表 + 2 圖）**

### 5.1 The Conventional Estimator Fails Its Own Null

以 26 個循環執行兩階段迴歸，結果表面上極為顯著（Table 3 左欄）。但在 r_b ≡ 0 的合成資料上重跑同一程序，回收出的假 r_b **中位數 0.0187，大於實測的 0.0143**。

**Table 3.** Two-stage apparent-parameter regression versus its own null (B = 200).

| Quantity | Observed | Null (r_b ≡ 0) |
|---|---|---|
| Correlation P_eq' vs 1/k_La | r = −0.935 | — |
| p-value of that correlation | 2.6 × 10⁻¹² | — |
| Recovered r_b (kg cm⁻² h⁻¹) | 0.0143 | median **0.0187**, 95th pct 0.0276 |
| **p vs null** | — | **0.735** |

> **正文要寫的因果解釋（一句）**：當壓力軌跡接近直線時，k_La 與 P_eq 的估計誤差沿擬合脊線正相關，於 P_eq'–1/k_La 平面上製造**與真實物理關係同號**的假相關。

### 5.2 Joint Estimation Is Nearly Unbiased

**Table 4.** Bias of the two estimators on identical r_b ≡ 0 synthetic data.

| Estimator | Recovered r_b (median) | 95th pct | Max | Bias reduction |
|---|---|---|---|---|
| Two-stage regression | 0.01872 | 0.02757 | — | — |
| **Single-step joint** | **0.00075** | 0.00515 | 0.00826 | **96%** |

實測 r̂_b = 0.01104 超出虛無分布之最大值，故 p < 0.005（B = 200）。

**Table 5.** Calibrated parameters and leave-one-cycle-out stability.

| Parameter | Value | LOO stability |
|---|---|---|
| P_eq (shared) | 0.9054 kg cm⁻² | ± 0.0046 (CV 0.5%) |
| **r_b (shared)** | **0.01104 kg cm⁻² h⁻¹** | ± 0.00029 (CV 2.6%) |
| k_La (τ = 1 min) | 0.0384 h⁻¹ | — |
| k_La (τ = 5 min) | 0.1489 h⁻¹ | — |
| k_La (τ = 10 min) | 0.1673 h⁻¹ | — |

**Table 6.** Channel decomposition at P = 1.05 kg cm⁻².

| Batch | Physical k_La(P − P_eq) | Biological r_b | Biological share |
|---|---|---|---|
| 1 min | 0.0056 | 0.0110 | 67% |
| 5 min | 0.0215 | 0.0110 | 34% |
| 10 min | 0.0242 | 0.0110 | 31% |

> **⚠ 必寫的兩句誠實聲明**（否則會被抓）：
> (1) 生物份額隨 τ 下降**並非活性下降**——r_b 三批共用同一值，是物理質傳被增強所稀釋。
> (2) 含 r_b 與不含 r_b 的模型在**逐循環預測**上差異不顯著（Wilcoxon p = 0.468）。正確表述為「r_b 被穩定且顯著地估計出來」，而非「加入生物通道改善預測」。存在性另有獨立證據：排氣目測甲烷達 31.6–43.0%。

### 5.3 The Reactor as a Self-Identifying Platform

控制器每次補氣即免費完成一次弛豫實驗。**12 天累積 26 次，即 2.2 次/天**，零生產中斷、零測試訊號。

**Table 7.** Learning curve of r_b precision (bootstrap resampling, 60 repeats).

| Cycles n | ≈ days | r_b | SD | CV |
|---|---|---|---|---|
| 3 | 1.4 | 0.01204 | 0.00431 | 35.8% |
| 8 | 3.7 | 0.01187 | 0.00250 | 21.1% |
| 16 | 7.4 | 0.01173 | 0.00175 | 14.9% |
| 26 | 12.0 | 0.01113 | 0.00129 | 11.6% |
| 60 | 27.7 | 0.01105 | 0.00078 | 7.1% |

精度隨累積循環數的**冪次為 −0.54**，與獨立樣本的理論值 −0.50 幾乎相同。此為關鍵證據：**每個循環貢獻近乎獨立的資訊**，而非重複量測同一漂移系統（後者冪次會趨近 0）。外推得：CV < 10% 需約 34 個循環（16 天連續運轉）。

## 6 The Cost of Trust: On-Device Budget

> **配置：約 1.5 頁（400 字 + 2 表）。這是全篇的邊緣運算核心。**

**Table 8.** Pipeline cost on two x86 platforms (identical script, auto-detected platform).

| Stage | Laptop (14-core) | Workstation (12-core) | Ratio |
|---|---|---|---|
| Cycle detection, streaming | 0.56 µs/sample | 0.100 µs/sample | 5.6× |
| Per-cycle feature extraction | 3.47 ms | 0.571 ms | 6.1× |
| **Joint estimate (Alg. 2)** | 0.878 s | **0.148 s** | 5.9× |
| **Bootstrap calibration, B = 200 (Alg. 3)** | ~3.0 min | **0.50 min** | 6.0× |
| **Calibration / estimate cost ratio** | — | **203×** | — |
| Multicore speedup of calibration | 6.2× (13 proc.) | 5.67× (11 proc.) | — |
| Local optimizer vs differential evolution | 0.78 s vs 30.8 s | 0.155 s vs 5.50 s | 35–39× |
| **Peak memory** | 326 MB | **330 MB** | **≈ 1.0** |

**四點結論，每點一段：**

**(a) 可信度的代價約為估計本身的 200 倍。** 產生一個 r_b 只需 0.15 s，但要讓它值得信任需要 200 次自助。這是邊緣裝置的核心兩難——而 §5.1 已證明，省下這筆錢的代價是輸出 p = 2.6 × 10⁻¹² 的假結果。

**(b) 但可以排程。** 串流偵測僅 0.1 µs/樣本，而循環間隔 6–15 小時。校準只需 0.5–3 分鐘，排在循環間的閒置期即可，完全不影響每分鐘的即時偵測。

**(c) 該配多核 CPU，不是 GPU。** 全程為數值最佳化，GPU 完全閒置（工作站確實配備 RTX 3060）。200 次自助彼此獨立，故隨核數近線性加速。

**(d) 記憶體足跡與平台效能無關**（326 vs 330 MB），據此可預估資源受限裝置的可行性。

**Table 9.** Cost of *detecting* GPU availability (same machine, same workload).

| | Without PyTorch | With PyTorch loaded |
|---|---|---|
| Joint estimate | 0.148 s | 0.162 s (+9%) |
| Per bootstrap | 0.151 s | 0.178 s (+18%) |
| **Peak memory** | **330 MB** | **637 MB (+307 MB)** |

## 7 Discussion and Limitations

> **配置：約 0.7 頁（250 字）。誠實但不自貶。**

**Scope of the claim.** 本文提供 r_b 的**定量值**，而非其存在性之證明；存在性由排氣甲烷 31.6–43.0% 獨立確立。

**Endogenous trigger.** 補氣由壓力閾值觸發，故本質較慢的循環既花較久到達任一壓力、又在該壓力下較慢（循環長度與平均速率相關 r = 0.66–0.89）。任何跨循環比較都須加入循環固定效應檢查。**建議將補氣改為定時觸發**以消除此混淆。

**Autocorrelation.** 1 分鐘取樣資料高度自相關，F 檢定會把數千個相關點當獨立而給出假的 p = 0。本文全程改用留一循環／留一批次交叉驗證。

**Sensor resolution.** pH 每循環僅 7–9 個量化階，對參數辨識與監督式預測**均無貢獻**（兩條獨立證據）。ORP 之慢速漂移僅 +2.26 mV h⁻¹，對上 ±20 mV 雜訊，需累積約 12 個循環才顯著。

**Falsification test (future work).** 以純二氧化碳進氣（無氫氣即無產甲烷）進行數小時封閉衰減，本方法應回收 r_b ≈ 0。此為對整套校準協定最強的否證檢驗。

## 8 Conclusion

> **配置：約 0.3 頁（120 字）**

在邊緣裝置上，產生估計值是廉價的，證明它不是假象則昂貴約 200 倍。我們證明既有的兩階段分離方案會產出與真實效應同號、同量級的假象，提出並校準了單步聯合估計取而代之，並量測其在實際硬體上的代價。閾值觸發的循環運轉使生產反應器本身成為持續累積辨識能力的平台，精度以近乎理論最佳的速率隨運轉時間改善。
