#### ⚠ 同日回覆否證了 CRPP 的架構推論

**設備方回覆：「補氣是補到某個壓力才停。」** → **P0 確實是設定點，CRPP 判錯架構。**

原因在資料上看得出來：P0 目標值離散（七月 1.16/1.17/1.19…）但實測有 **±0.02 抖動**
（致動遲滯＋一分鐘取樣的過衝），**±0.02 ＝ 2 個量化步階**，恰好打垮離散度判準。

**CRPP 的宣稱已改寫**：由「判定哪些通道**是**設定點」改為
「判定哪些通道**在感測解析度與致動雜訊下仍可用**為控制面」。
消融結果不變（含 P0 → 2/4；排除 → 3/4），故實務結論成立：

> **理論上正確的控制通道集合 ≠ 實務上最佳的。**
> 致動雜訊超過數個感測 LSB 時，真設定點會變得不可用，納入反而傷害下游任務。

`scratchpad/setpoint_purity.py`：**P0（補氣上限）不是乾淨的設定點。**

| 通道 | 前 3 值涵蓋 | vs log kLa | 判讀 |

**決定性證據（Algorithm 4）**：
- 以雙指數（$r_b \equiv 0$）為真相產生虛無 → **100% 複製實測值**（無噪聲即 0.01099 vs 實測 0.01104，p = 0.40）
- 完整管線對真值為 0 的資料 → **5/5 判定顯著**

**根本原因（文獻佐證）**：OTR/OUR 分離是既有標準實踐，但**標準做法依賴溶解氣體電極**。
**缺的是觀測量，不是方法。**

### ⚠ 其他已收回的說法

- ✗ 物理／生物份額 67/34/31%（建立於已被否證的常數 $r_b$ 假設）
- ✗ τ 槓桿可用
- ✗ 「三種方法收斂於 0.004」（ORP 尾段顯示 H₂ 已耗盡，測到的是基質耗盡不是 operating 速率）
- ✗ 1:1 與 4:1 的速率差可歸因於通道比例
- ✗ CR-DL 為已驗證模型（**兩次獨立設定皆未通過**；K_H 兩次都頂在上界 2.0 → 資料不支持飽和形式）
- ✗ 「變點偵測在未被告知組成的情況下抓到 1:1 起點」（$k_La$ 代理**有**收到 $f_{\mathrm{CO_2}}$；組成盲的是未校正速率序列）

**生物活性的存在**由排氣甲烷 **31.6–43.0%** 獨立確立——這是事實，只是**數值**測不到。

## 三、新穎性的誠實定位

**不主張**：新的統計方法。變點偵測、FPCA、WSINDy、集合歸屬、Monod+傳質模型
——**全部是既有方法**。OTR/OUR 分離亦為既有標準實踐。

**主張**：

1. 把既有方法組成一條**僅用壓力、可線上執行**的探勘管線，並以**外部已知事件驗證**
2. 在此裝置類別上，**首次以近一年生產資料**做系統性的製程狀態還原
3. 對「僅有頂空壓力時能還原什麼」給出**明確的可辨識性邊界**與可移植的檢定協定

> **這是應用與實證型的貢獻，不是方法學突破。**
> 以 ICEA 的邊緣運算議程而言，「感測受限下的製程狀態還原」是切題且份量足夠的題目。
