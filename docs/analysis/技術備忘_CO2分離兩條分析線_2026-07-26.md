| 提報 | 李承育 |
| 對象 | 洪博 |
| 主旨 | 就「分離 CO2 物理溶解與菌種消耗」提出兩條可執行的分析路線，並說明目前實驗設計的適配程度與建議調整 |

## 一、問題與背景

核心目標是把反應槽內**兩個同時發生的機制**分開量化：

- **物理溶解**：CO2 溶入液相（依亨利定律，趨近飽和即變慢）
- **生物消耗**：嗜氫甲烷菌消耗溶解態 CO2（CO2 + 4H2 → CH4 + 2H2O）

壓力下降量測到的是**兩者的總和**。歷史資料上先前 12 種方法均未通過決定性檢定
（詳見 2026-07-16 日報）。本備忘釐清「為什麼難」，並提出兩條難度不同、皆可執行的路線。

## 二、關鍵發現：分離的困難是「結構性」的，與演算法無關

以機理模型（物理項 kLa·驅動力 + 生物項 Monod）＋合成資料＋profile likelihood
做可辨識性測試，結論明確：

- **穩態下兩通量相等**（溶解通量 ≡ 生物消耗通量，是同一個數），從壓力下降**無從分辨**。
  實測物理速率 kLa 在穩態資料下信賴區間達 ±160%，在含**暫態**的資料下收斂到 ±0%。
- 因此分離的槓桿是**暫態**（液相遠離飽和、兩通量暫時解耦），不是更複雜的模型。
  **換神經網路、換更新的演算法都不會改變這個結構限制**——這是實驗設計問題，不是算法問題。
- 生物速率參數（Vmax）本身不可辨識（Monod 低濃度段與 Km 共線），故生物量應以
  **「總通量 − 已釘死的物理通量」殘差**取得，而非直接擬合。此即先前唯一站得住的
  分離（2026-04-07 換液後暫態，估得物理 48.6%／生物 51.4%，惟 n=1 待新實驗確認）之原理。

此結論與生物甲烷化文獻一致：主流做法為灰箱模型（gas–liquid 傳質 kLa + 生物動力學），
物理常數（亨利溶解度 C\*、碳酸鹽平衡）由文獻／熱力學固定，僅估少數反應器特定參數。

## 三、兩條分析線（工具已建置並驗證）

| | 關聯分析 | 機理分離 |
|---|---|---|
| 回答 | 平緩化**是不是**生物造成 | 溶解 vs 消耗**各多少** |
| 腳本 | `co2_covariate_association.py` | `co2_greybox_identifiability.py` |
| 難度 | 中，**現有 9 批次即可** | 難，**需暫態段** |
| 現況 | 合成資料雙向驗證通過 | 可辨識性已量化，待暫態資料 |

**關聯分析（建議先做）**：判斷斜率平緩化是生物（產甲烷稀釋 CO2）還是物理（趨近飽和）。
判準為「控制循環時間 n 後，平緩化是否仍隨進氣前 ORP（菌群成熟度代理）顯著變動」。
統計上以「批次分群的叢集穩健標準誤」處理同批次循環的偽重複，有效樣本數折算至批次層級。
此路線**用現有 DOE 就能執行**，且直接回答洪博提出之「產甲烷使斜率平緩」假說是否成立。

## 四、目前實驗設計的適配程度

以 2026-07-19 定案設計（循環時間 n=1／5／10、每水準 3 重複、共 9 批次、壓力閾值排氣至 0.9）評估：

| 需求 | 現況 | 判定 |
|---|---|---|
| 因子有變異（n；ORP 隨菌齡變） | 有 | 適配 |
| 混淆因子有量測（進氣前 ORP） | 系統逐循環自動記錄 | 適配 |
| 排氣至 0.9（訊號窗口較寬） | 已採用 | 適配（有利軌跡擬合）|
| 足夠**獨立**重複 | 同水準 3 批為偽重複 | 檢定力偏低 |
| 打破「n 與菌齡共線」 | n 按固定順序、與天數對齊 | **未處理** |
| 保留**暫態**（機理分離所需） | 目前多為穩態窗口 | **未納入** |

**結論**：
- 對**關聯分析**：現有設計**基本適配**，尤以「進氣前 ORP → 速率／平緩化」最乾淨、可直接做。
- 對**機理分離**：現有設計**不足**，因穩態窗口結構上分不開。

## 五、建議（兩項近乎零成本、一項待討論）

1. **打亂 n 的執行順序**（如 5→1→10…），使菌齡不與 n 對齊，消除共線。成本僅換排程順序。
2. **每日穿插一個固定參考 n**（如每天先跑一次 n=5），追蹤菌群漂移曲線，供事後扣除菌齡效應。
3. **納入純物理對照段**（換液初期或滅活對照的低活性純溶解）——這是機理分離可行的前提，
   用來獨立釘死物理項 kLa／C\*。若無法新增，退而用文獻亨利常數＋既有 `co溶入液體` 資料，
   代價是分離結果不確定性較大。
