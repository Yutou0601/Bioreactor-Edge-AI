## 摘要

厭氧消化的最後一個階段將二氧化碳轉換為甲烷，然而菌群消耗氣體的速率通常
無法直接從運轉中的反應器讀出。頭空壓力同時因兩個原因下降——生物消耗氣體，
以及新注入的氣體溶解——而慣常的區分方式需要第二套儀器，例如量測槽體重量。

本文僅從壓力紀錄本身回復生物速率。該反應器為微正壓循環槽體，每當壓力低於
控制器閾值即補氣，因此每次補氣都開始一段不受外力干預的下降，日常運轉即可
提供每日約兩次的弛豫實驗，且不影響生產。

困難在於單一段下降中，物理與生物的貢獻幾乎可以互換，由單一循環估得的兩個
量呈現強相關。我們的解法是以模擬校準估計器：模擬沿用每個實測循環自身擬合
所得的條件，僅替換為已知的生物速率，使估計器的扭曲得以被量測並移除，而非
以假設迴避。

在 301 個通過篩選的循環上，校準排除了「生物速率為常數」的假設，並給出修正
後的消耗速率 **0.0107 kg/cm²/hr**，精度 **7.6 %**，其中 4.0 % 為系統性成分，
不隨紀錄延長而縮小。以分類器為基礎的雙樣本檢定確認，模擬器重現了我們檢驗過
的所有邊際軌跡性質。

**關鍵詞**：製程資料探勘、實用可辨識性、厭氧消化、量化感測、生物甲烷化

## 1. 簡介

本文的資料來自一座工業級生物甲烷化反應器，其設計為**階梯式分壓**（圖 1）：
氫氣與二氧化碳於高壓預混，降壓後使菌液維持於微正壓，再以低壓排至氣體分析
儀；同時循環泵持續將頭空氣體自槽底以氣泡形式送回液相。氣液傳質是生物甲烷化
的限制步驟，將氣體加壓並循環正是本反應器的因應方式。其記錄程式每分鐘記錄
一筆壓力值，量化階為 0.01 kg/cm²。決定何時補氣的控制器是一個封閉單元：
其設定點、狀態與決策時刻皆未被記錄，儀器無法加裝，運轉中的槽體也不允許
施加任何激發。

這份紀錄真正提供的是**重複**。由於補氣是閾值觸發，兩次補氣之間的每一段下降，
都是這座工廠對自己執行的一次弛豫實驗，每日約 2.2 次，於整個記錄期間共 351 次。
從這些下降中讀出生物速率，正是厭氧消化量測問題的縮影：在封閉頭空中，甲烷化
每產生一莫耳氣體即消耗五莫耳而使壓力下降，同時新注入的二氧化碳溶解也使壓力
下降。慣常的解法是加入第二個物理通道——例如壓力式生物甲烷潛勢法以量測瓶重
將洩漏與轉化分開——而這個選項在此不存在。

> **圖 1** 反應器的階梯式分壓設計。氣體自反應物層經菌液層降至生成物層，
> 使菌液維持微正壓，下游分析儀則接近常壓。循環泵將頭空氣體自槽底以氣泡
> 送回，這正是維持反應氣體持續溶解的機制。頭空中標記為 PT 的傳感器是本文
> 唯一使用的通道；開啟閥 V3 的控制器為封閉單元，其狀態從未被記錄。

困難在於單一段弛豫不足以分開兩個通道。將下降寫成

$$P(t) = P_{eq} + A e^{-kt} - r_b t \tag{1}$$

其中指數項承載趨近平衡的物理過程，線性項承載定速率的生物移除。當觀測窗內
的 $kT$ 很小時，$e^{-kt} \approx 1 - kt$，兩項即可互換。此類實用可辨識性
問題在厭氧消化建模文獻中是公認的未解問題，而且在專為生物甲烷化撰寫的機理
模型中仍然存在：ADM1 針對此製程的近年擴充，其生物參數與傳質參數必須由同一
組量測共同辨識。

### 本文貢獻

1. **在領域慣以加通道解決之處給出速率。** 我們在單一量化壓力通道上正面
   處理簡併，而非如壓力法慣例以第二套儀器將其溶解。
2. **一個在擬合之前執行的篩選。** 既有的可辨識性診斷都是從已擬合的模型
   計算而來；我們改為僅由原始軌跡的形狀排除簡併循環，門檻由合成資料在
   感測器自身量化階下的回收表現決定（式 2、Listing 1）。
3. **由控制迴路提供的激發。** 閾值觸發的補氣使這座工廠自我激發：351 次
   弛豫實驗，對生產沒有任何強加。

本文使用的統計工具皆為既有方法，於採用時逐一標明來源；我們主張的是這些
工具的組合，以及使其得以運作的條件。

## 2. 相關研究

三條研究線與本問題直接相關，其中第一條最能界定我們可以主張的範圍。

### 2.1 從單一氣體軌跡取出兩個速率

我們面對的估計幾何已有五十九年歷史。**動態除氣法**自一條**單一**的溶氧
軌跡（跨越曝氣中斷）同時取出傳質係數與生物攝取速率：一個純量通道、一個
傳質項、一個生物項。我們完全繼承這個結構，不在其中主張新穎性。

不同之處在於條件：他們的觀測量是連續讀取的，我們的壓力量化得極粗，
生物貢獻於一個典型循環中僅跨約十五個量化階；他們的實驗方案主動施加中斷，
我們不得擾動生產中的槽體；他們報告點估計，我們則報告經簡併校準的聚合值。
動態壓力法的各種變形同樣依賴刻意施加的階躍，並將生物項視為可忽略或已由
其他方式獨立得知。

### 2.2 加入通道而非解決簡併

在生物／物理之分真正重要的場合，領域的做法是去量測別的東西：壓力式生物
甲烷潛勢試驗以量測瓶重將洩漏與轉化分開，那是第二個且物理上獨立的觀測量。
這是穩健的做法，也是簡併鮮少被正面處理的原因。當某個量根本無法儀器化時，
領域近年愈來愈傾向從既有量測推論該量；我們的問題屬於此類，差別在於我們
沒有可供學習的標註資料。本文的條件移除了加通道這個選項，使可辨識性問題
無可迴避。

### 2.3 可辨識性診斷

實用可辨識性在厭氧消化建模中是公認的未解問題。標準診斷工具是**輪廓概似**
（profile likelihood），近年並有綜述將可辨識性與參數估計、模型預測串接
討論；指數擬合本身的病態條件則早由 Varah 刻畫。兩者都是**從**一個擬合結果
計算而來。這正是我們的篩選所填補的空隙：我們必須在還沒有可信的擬合之前，
就決定哪些循環值得擬合。

## 4. 方法

### 4.1 切分、清理與模型形式

清理移除設備操作人員指認出的兩類污染：**洗管日**（該日槽體被反覆循環以清洗
管線）以及**補氣區間本身**。

切分規則為：凡壓力相對運行最小值上升超過 0.03 kg/cm²，或取樣間隔超過 1 小時
者即切開；短於 4 小時或深度不足 0.10 kg/cm² 的區段捨棄；任一日若出現超過六個
區段，即視為洗管日並整日剔除；每個區段的前 3 分鐘移除，因為補氣被視為瞬時。

式 (1) 是以 AIC 在「純線性」與「純指數」兩個對照之中選出的，於 78.1 % 的
循環上勝出。其簡併不是我們實作上的缺陷，而是指數擬合自 Lanczos 以來即被
理解、並經 Varah 量化的性質；以 Gutenkunst 等人的語彙，此模型沿著「以 $A$
與 $k$ 交換 $r_b$」的方向是**鬆散的**（sloppy）。篩選在實際資料上顯示了
其後果：兩組 $r_b$ 相差 2.5 倍的擬合，其殘差平方和竟落在彼此的 1 % 之內。

### 4.2 一個在擬合之前的篩選

輪廓概似能夠診斷此種簡併，但它是**從**一個擬合結果算出來的，而在這份資料上，
擬合結果正是我們尚不信任的東西。因此我們在擬合任何東西之前，先就原始軌跡的
形狀進行篩選。

篩選統計量為正規化的中點曲率

$$c = \frac{y(0) - y(T/2)}{y(0) - y(T)} \tag{2}$$

對一段完全筆直的下降，其值恰為 0.5——此時式 (1) 的兩項無法區分——並隨軌跡
彎曲而上升。當 $c \ge c^*$ 時保留該循環，其中 $c^* = 0.45$ 是由已知真值
$r_b = 0.012$ 的合成循環回收表現所固定，**而非在實際資料上挑選**：低於該值
時，回收的中位數偏誤超過 25 %。Listing 1 給出篩選與估計器；兩者僅以 NumPy
執行，符合監控電腦 60 MB 的預算。

> **Listing 1. 從單一循環取出可信的速率**
> 過於筆直、不足以約束鬆弛常數的循環，在嘗試任何擬合之前即被排除。其後為
> 式 (1) 的輪廓化最小平方估計器。將 $k$ 的全部 150 個網格值當作一個堆疊的
> 3×3 系統求解，可使掃過 351 個循環的完整流程維持在一秒以內。

### 4.3 把簡併校準掉

在保留的循環上，擬合所得的 $\hat r_b$ 與 $\hat k$ 相關係數為 $\rho = 0.831$。
若照字面讀，這看起來像是「估計值為假影」的證明。但它單獨無法解讀：
$\hat r_b$ 與 $\hat k$ 共同吸收同一段下降，因此**即使真值固定**兩者仍會相關。
真正的問題是：這個相關**超出**固定真值本身已經產生的程度多少。

因此我們採用 Schuemie 等人意義下的**經驗校準**，以「由已知真值的案例估得的
虛無」取代理論虛無 $\rho = 0$。該虛無由**設計配對模擬**產生（Listing 2）：
每個真實循環貢獻它自己擬合所得的 $\hat k$、$\hat A$、$\hat P_{eq}$、時長、
殘差尺度與 AR(1) 係數，**僅替換真實的 $r_b$**，其結果再通過完全相同的流程，
使估計器的扭曲同時出現在比較的兩側而互相抵消——這正是間接推論的邏輯。

我們對該方法的調整在於負對照的來源：他們的負對照是「被認為屬虛無」的觀察性
案例，我們的則是沿用真實設計的模擬，因而能把真值**精確固定**而非加以假設。

> **Listing 2. 量測並移除簡併偏誤**
> 以此程序掃描 $\beta$ 即得圖 3 的曲線；恆定真值（$\beta = 0$）給出
> $\rho = 0.278 \pm 0.056$，與 $k$ 獨立的真值給出 $\rho = 0.143 \pm 0.048$，
> 相對於實測的 0.831。

模擬器本身必須先被證明是充分的，否則基準毫無意義。我們採用**分類器雙樣本
檢定**（由 Friedman 為此目的提出、Lopez-Paz 與 Oquab 重新檢視、並由 Dalmasso
等人應用於模擬器與代理模型的驗證）：訓練一個分類器去區分真實軌跡與模擬軌跡，
AUC 接近 0.5 即表示兩者不可區分。雜訊模型在半數循環上校準，AUC 則在保留的
另一半上計算。

## 5. 結果

### 5.1 速率

篩選自 351 個循環中保留 301 個。在這些循環上，$r_b$ 的中位數為
0.0117 kg/cm²/hr。相對於「真值為純指數」（即 $r_b \equiv 0$、全部壓力損失
皆屬物理）的設定誤差虛無，實測中位數對應的置換檢定 $p = 0.024$。因此壓力
下降中含有一個純物理模型無法產生的成分。

我們要強調這個推論的**方向**：它排除純物理的解釋；它本身**並未**確立該殘餘
成分即為生物性。

### 5.2 相關係數的意義

我們不去假設 $k$ 依賴的函數形式，而是把它的**強度**當作待反解的量。將真值
寫成 $r_b(k) = r_b^0 (k/k_{med})^\beta$——採冪次形式，使 $r_b$ 不可能轉為
負值，且中位真值對每個 $\beta$ 都等於 $r_b^0$——接著掃描 $\beta$，於每個值
上執行完整的配對流程，得到圖 3(a) 的校準曲線。

**表 1** 回復的速率及其背後的校準檢查。基準各列為設計配對模擬，其中真實速率
為已知，因此估計器自身的扭曲可以直接讀出。

| 量 | 值 | 註 |
|---|---|---|
| 切分出的循環 | 351 | 閾值規則 |
| 保留的循環 | 301 | $c \ge 0.45$ |
| **校準後 $r_b$** | **0.0107 kg/cm²/hr** | 95 % 區間 [0.0100, 0.0116] |
| 　抽樣成分 | ± 2.8 % | 301 個循環的拔靴法 |
| 　系統成分 | ± 4.0 % | 跨相容集合 |
| 純物理參照 | $p = 0.024$ | 純指數真值 |
| 實測 $\rho(\hat r_b, \hat k)$ | 0.831 | |
| 校準，$\beta = 0$（恆定） | 0.278 ± 0.056 | 假影水準 |
| 基準，$r_b$ 與 $k$ 獨立 | 0.143 ± 0.048 | |
| 相容集合 | $0.20 \le \beta \le 0.80$ | 在校準散布之內 |
| 未修正的輪廓化中位數 | 0.0117 kg/cm²/hr | 修正前 |
| 校準修正量 | −9.1 % | 篩選效應 ≤ 3.9 % |

**恆定真值被排除**：$\beta = 0$ 僅產生 $\rho = 0.278 \pm 0.056$，相對於實測的
0.831 差距約十個標準差；而若只讓 $r_b$ 有變異卻不與 $k$ 掛勾，相關反而進一步
降到 0.143。$\beta$ 介於 0.20 至 0.80 的真值可在校準散布之內重現實測相關，
我們即以此相容集合往下推。

同一組校準接著提供了**修正量**（圖 3(b)）。在相容集合上，估計器把聚合中位數
高估了 +5.2 % 到 +14.0 %，其中篩選本身的選擇效應至多佔 3.9 %。將其反解即得
校準後的速率

$$r_b = 0.0107\ [0.0100,\ 0.0116]\ \text{kg/cm}^2\text{/hr} \tag{3}$$

相當於對未修正的輪廓化中位數做了 −9.1 % 的修正。

該區間合成了兩個性質不同的來源。對 301 個循環重抽樣，中位數的抽樣不確定度
為 ± 2.8 %，此值會隨記錄持續而縮小；跨相容真值的散布為 ± 4.0 %，此值**不會**
縮小，因為它取決於校準能多銳利地區分族內成員，而非取決於觀測到多少循環。
由於修正是以商的形式進入，我們以蒙地卡羅自兩者同時抽樣，得到式 (3) 的
± 7.6 %——**這就是單一量化壓力通道能將生物速率定到的精度，也是本文主要的
量化結果**。

### 5.3 參照分布如何建立

$p = 0.024$ 這個檢定的效力取決於虛無被允許包含什麼（Listing 3）。對每個保留
的循環，我們先擬合雙參數形式 $P(t) = P_{eq} + A e^{-kt}$，即式 (1) 中 $r_b$
被強制為零者，使擬合出的虛無重現該循環自身的平衡值、振幅與鬆弛常數。接著由
該擬合重新生成循環，加入以其自身殘差尺度產生的 AR(1) 雜訊，量化至
0.01 kg/cm²，再通過完全相同的篩選與估計器。掃過全部 301 個循環即得純物理
真值下聚合中位數的一次抽樣；60 次抽樣構成其虛無分布。

> **Listing 3. 排除純物理的解釋**
> 參照分布是逐循環擬合的，因此除了生物速率本身之外，它繼承了對立假設所擁有
> 的每一個自由度，並且通過相同的量化、篩選與估計器。

有兩個細節重要。其一，被比較的統計量是**聚合**中位數而非單一循環，因為拿
一次虛無抽樣去對比一個聚合觀測值，等於把不同尺度的量放在天平兩端。其二，
虛無是逐循環擬合而非集中擬合，因此它被賦予了除 $r_b$ 之外對立假設的所有
自由度。在該虛無之下，聚合中位數為 $+0.00008 \pm 0.00010$ kg/cm²/hr，
比實測的 0.0117 低兩個數量級。

### 5.4 對觸發選擇之端點的穩健性

切分讓每個循環結束於補氣前的最後一個取樣點，而該點之所以被選中，**正是因為**
壓力下降到足以觸發，因此它位於底層趨勢之下：疊加殘差顯示末點平均為循環振幅
的 −0.068，而其餘位置為 ±0.006。由於線性斜率在端點處最敏感，這是一條可能
使速率被高估的合理途徑。

裁切可以了結此事。移除每個循環最後的 5 至 90 分鐘，$r_b$ 的中位數僅在
0.0113–0.0122 kg/cm²/hr 之間移動，帶寬為 ±5 %；而一組完全沒有觸發選擇的
設計配對模擬，在相同裁切下漂移幅度相當：約 700 個取樣點中的一個異常點，
其槓桿不足以扳動斜率。因此該速率並非切分位置造成的假影。

## 6. 限制

前述數字所能支持的範圍受三項限制界定。

**其一**，聚合中位數是可回復的，但逐循環的估計值不是：個別值散布極廣且與
$\hat k$ 耦合，因此本文任何內容都不足以支持把單一循環讀作一次速率量測。
速率上的 ±7.6 % 之中，±4.0 % 的系統性部分是由校準而非由記錄長度決定的；
要收窄它，需要 $r_b(k)$ 的函數形式本身，而那需要第二個化學通道才能提供。

**其二**，即使十項邊際特徵全部吻合之後，模擬器仍在 AUC = 0.695 可與真實區分，
表示不吻合之處位於我們尚未辨識出的**聯合結構**。因此配對基準只是近似，我們
也不在此模擬器上嘗試模擬式推論：由一個設定錯誤的模擬器學到的後驗，會是又窄
又錯，而不只是不確定。

**其三**，部署目標是一台具 4 GB 記憶體、可用約 60 MB 的監控電腦，其約束來自
**函式庫體積**而非演算法成本——NumPy 單獨佔 27 MB，完整科學運算堆疊則為
129 MB——因此整條流程僅以 NumPy 撰寫。這也是我們未採用學習式模型的原因：
困難在於可辨識性而非函數逼近，額外的參數只會以更低的可見度吸收同一個簡併。

## 7. 結論

一座閾值觸發的微正壓反應器會對自己執行弛豫實驗，而即使唯一的觀測量是量化階
0.01 kg/cm² 的單一壓力通道，這些實驗仍承載著可回復的生物速率。要正確讀出
這個通道，必須以**設計配對的虛無**而非理論虛無來校準估計器，因為兩個擬合項
之間的原始相關係數，單獨是無法解讀的。加入第二個通道——一個成分錨點，或一個
訊噪比改善的氧化還原訊號——是通往逐循環結果的直接途徑。
