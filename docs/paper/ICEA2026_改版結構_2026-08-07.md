## 新穎性的誠實定位（查證後）

**三個統計方法全是先前技術，一律寫成「引用並應用」**：
配對基準模擬＝間接推論 [gourieroux1993] ／經驗校準 [schuemie2014]；
分類器雙樣本檢定＝[friedman2003, lopezpaz2017]，且 [dalmasso2020] 已用於同一用途；
形式回收檢定＝model recovery [wilson2019] Rule 8。

**真正主張的貢獻**：
- **(C1)** 厭氧消化領域首次在**單一量化壓力通道**上正面處理生物速率與傳質項的
  實務不可辨識性。領域現況：可辨識性是公開難題 [donosobravo2011]；
  現行做法靠**加第二個物理通道**（瓶重）分開生物與物理 [hafner2018]——本文拒絕加。
- **(C2)** 裝置本身提供**內生激發**：閾值觸發補氣使反應器每天自發產生 2.2 次
  弛豫實驗，351 段軌跡全部來自正常生產，未施加任何外部擾動。
- **(C3)** 誠實報告**失敗的 model recovery** 並讓它否決 r_b(k) 的形式宣稱。

**⚠ 必須自己先引的威脅**：[bandyopadhyay1967] 動態除氣法從單一溶氧軌跡同時取出
kLa 與生物耗氧率，結構同構且早 59 年。§2 明講四個差異：
氣相壓力非溶氧探針／0.01 量化／處理不可辨識性非給點估計／氫營養型甲烷化非好氧發酵。

## Algorithm 欄位（4 個）

**Alg. 1　Cycle segmentation and cleaning**
```
輸入：時間 h[], 壓力 P[], 時戳 ts[]
1  以「P 較谷值回升 > 0.03」或「取樣間隔 > 1 hr」切段
2  保留 時長 ≥ 4 hr 且 落差 ≥ 0.10 的段
3  每日切段數 > 6 者判為洗管線，整日排除
4  每段起點後 3 min 排除（補氣視為瞬間）
輸出：清理後的循環集合
```

**Alg. 2　Pre-fit curvature screen**（唯一未找到先前技術者，屬工程貢獻）
```
輸入：循環 (t, y)
1  curv ← (y[0] − y(T/2)) / (y[0] − y(T))      // 只看形狀，不需擬合
2  若 curv < 0.45 則捨棄                        // 門檻由合成資料校準
輸出：保留與否
```

**Alg. 3　Matched-baseline degeneracy test**（引用 [gourieroux1993, schuemie2014]）
```
輸入：真實循環的擬合設計 {k̂, Â, P̂eq, T, σ̂, φ̂}, 候選真值 r_b
1  對每個循環：沿用其**自身**設計，代入已知 r_b，加 AR(1) 雜訊、量化
2  走**完全相同**的管線（Alg.1 → Alg.2 → 擬合）
3  計算摘要統計量 ρ(r̂_b, k̂) 與中位數
4  重複 R 次得基準分布
輸出：實測值相對基準的位置
```

**Alg. 4　Recovery-calibrated form selection**（引用 [wilson2019] Rule 8）
```
輸入：候選形式集合 F, 真實設計
1  對每個 f ∈ F：以 f 為真值產生資料，走 Alg.3 的管線
2  在切半的另一半上為每個候選形式評分
3  若 argmin 分數 ≠ 投入的 f  ⇒  **形式不可分辨，不得宣稱**
輸出：可分辨性判定（本文為「不可分辨」）
```
