# ORP 數據校準說明

2026-08-20　李承育　供洪博參考

---

## 一、洪博的疑問是對的，而且資料證實了

疑問：分組結果裡出現「+2 mV」，但真實 ORP 應該在 −600 多到 −400 多。

查證結果（46 個檔案、62,640 筆逐行解析）：

| 項目 | 數值 |
|---|---|
| 紀錄檔裡的 ORP | **337 ~ 610 mV，全部為正** |
| 加負號後的真值 | **−610 ~ −337 mV** |
| 中位 | −568 mV |
| 實機表頭（設備照片） | 顯示 **−585 mV**，同時刻紀錄裡是 **585** |

**結論：記錄器只存絕對值，真值為負。** 洪博說的範圍與資料完全吻合。

## 二、「+2 mV」不是量錯，是定義的問題

程式裡的 `dORP` 定義是**該循環末筆讀數減首筆讀數**，也就是**端點差**。

但一個循環裡 ORP 的實際行為是（洪博計畫簡報自己寫的）：

> 輸入新氣體時會急遽下降，然後會有週期性的高低起伏回復到 550 多的高度

所以：

```
補氣後急降 100 mV  →  回升 98 mV  →  端點差 = +2 mV
```

**擺幅有 100 mV，端點差卻只有 2 mV。中間的過程被完全丟掉。**

這一項我方會修正論文用詞：原文寫 "redox excursion（擺幅）"，
與程式實際計算的端點差不符。

## 三、參考電極：兩個看似矛盾的數字其實都對

先前紀錄中另有「約 −357 mV，與文獻相符」的說法，與 −568 mV 對不上。
原因是**參考電極不同**：

```
現場表頭讀數（對 Ag/AgCl 參考電極）      −568 mV
換算到標準氫電極 SHE（約 +200 mV）        約 −368 mV
```

**給外部看的數字必須標明是對哪個參考電極**，否則會被認為與文獻不符。

## 四、換算後落在文獻的最適區間內

| 來源 | 產甲烷的 ORP 條件 |
|---|---|
| Vongvichiankul et al. 2017 | 最適 **−335.63 ± 28.97 mV** |
| Ao et al. 2021 | 不穩定門檻 **ORP > −540 mV**（中溫雞糞） |
| 文獻共識區間 | 約 **−200 ~ −400 mV** |
| **本反應器（換算至 SHE）** | **約 −368 mV** |

**我們的數值落在文獻的最適窗口內。**

這同時說明兩件事：菌所處的還原環境正常；以及參考電極的換算是正確的
（若不換算，−568 會看起來偏離文獻甚遠）。

## 五、⚠ 能說什麼、不能說什麼

ORP 是**混合電位**，同時受氫、pH、溶解二氧化碳影響，不是單一物種的探針。

| | |
|---|---|
| **可以說** | ORP 是厭氧環境健康度與製程穩定性的指標，適合作為早期預警 |
| **不能說** | ORP 可以定量反映甲烷菌的產氣速率 |

我方論文因此只把 ORP 當作**順序**上的一致性檢核，不當作速率量測。
文獻上的用法也是預警與穩定性監控，而非速率計。
