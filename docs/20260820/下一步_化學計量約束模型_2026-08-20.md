# 投稿後的第一個工作項：化學計量約束的狀態空間模型

2026-08-20 擬。**ICEA 2026 投稿完成前不動手。**

---

## 為什麼是這個

2026-08-17 到 08-20 試了六種新方法想從同一支壓力通道多榨出資訊：

| 嘗試 | 結果 |
|---|---|
| 位準跨越（遲滯） | 失敗，跨越數多算 3 倍 |
| 位準跨越（單調包絡） | 結構對，0.0170 偏高 |
| 速率空間漸近線 | 簡併原封重現，0.0178 |
| 跨循環時間不對稱 | 安慰劑沒過，否決 |
| 族群共享輪廓 | 極陡但給 0.0025，模型已知設定錯誤 |
| kT>7 尾段斜率 | 結構上無簡併，0.0177，但 β 落在相容集合外 |

**六次方法宣稱全部撞前人的題。結論：瓶頸是資訊，不是方法。**

而 2026-08-20 的甲烷對帳證明了**新資訊確實存在而且免費**：
化學計量 `CO2 + 4H2 → CH4 + 2H2O` 給出硬上限

```
CH4 生成 / 氣體消耗  <=  0.25
```

三批實測 0.217 / 0.168 / 0.193，全部落在上限內。
**現行估計器完全沒有用到這道約束。**

這也正是論文結論自己指的方向：
> "Adding a second channel—a composition anchor or an improved redox
> signal—is the direct route to a per-cycle result."

## 架構

```
狀態    n_tot   頭空總莫耳（∝ 絕對壓 × V_head / RT）
        n_ch4   頭空甲烷莫耳
        c_diss  溶解相（CO2 為主）

觀測    壓力    每分鐘、量化 0.01 kg/cm2、連續
                → 用**區間設限似然**，不要用最小平方
                  （sigma=0.0065 < delta=0.01，量化不是雜訊）
        CH4     僅排氣時、稀疏，但每筆都是硬約束

耦合    d(n_ch4)/dt = (1/4) × 生物移除速率
        生物移除 + 物理溶解 = 總移除（由壓力觀測到）
```

### 兩個關鍵設計

**一、量化要當設限處理。** 現行管線把量化當高斯雜訊做最小平方，
但殘差尺度比一個量化階還小，那個近似在此設定錯誤。改用

```
L_i = Phi((y_i + d/2 - P(t_i))/s) - Phi((y_i - d/2 - P(t_i))/s)
```

**二、CH4 觀測是約束不是資料點。** 它稀疏（一批一次），但每一筆
把整批的生物累積量釘住，遠比多幾個壓力樣本有價值。

## 現在就要開始累積的資料（零成本，有時效）

> **請洪博從今天起，每一次排氣都記下：**
> 1. 排氣當下的 CH4 峰值（%）
> 2. 排氣當下的 CO2 峰值（%）
> 3. 該輪的起點與終點反應槽壓力（錶壓）
> 4. 該輪的總時數
> 5. 進氣後基準的 CH4（洗管線後）

每一次排氣＝一道硬約束。目前只有 3 筆；累積到 20 筆模型才有槓桿。
**資料要時間長出來，所以這件事越早開始越好，不必等投稿完。**

## 已知限制（先寫下來，免得日後高估）

1. **只能做到「每批」，做不到「每循環」**——除非 CH4 逐循環量測。
   目前一批只排一次氣，約束密度就是一批一個。
   → 要問設備方：能否提高排氣取樣頻率而不干擾生產？
2. **起點 CH4 分率極度敏感**。批次 1 若把起點設為 0%，比值衝破上限。
   這個數字的量測程序要標準化。
3. **CH4 溶解被忽略**。微溶但非零，會低估生成量。
4. **頭空體積仍未定**。莫耳換算目前繞開它（用 1L 預混槽那一側），
   但狀態空間模型若要顯式寫 n_tot 就需要它。
   → 最乾淨的作法是請設備方**直接量**（記錄加了多少公升液體），
     不要再從一分鐘取樣的壓力硬挖，我試過，散布跨 20 倍。

## 要一併查清楚的三個「論文值偏低」跡象

三條獨立路徑同向偏離，下一篇的第一個問題就是這個：

| 路徑 | 值 | 方法 |
|---|---|---|
| kT>7 尾段斜率 | 0.0177 | 結構上無簡併的子樣本 |
| 化學計量對帳（批次 2、3） | 0.028 | 獨立的化學通道 |
| beta 反演張力 | beta≈0.14 | vs 論文相容集合 [0.20, 0.80] |
| **論文** | **0.0126** | 全資料集中位 |

三者都有選擇性（高 k 子樣本、菌況最好的時期），不能直接說論文錯。
但**三個獨立方法同向，不是可以忽略的巧合**。
