## 三項發現

**一、ORP 量到的是端點差，不是擺幅。**
紀錄 337~610 mV 全為正，真值 −610~−337（記錄器只存絕對值，實機表頭
顯示 −585 而紀錄裡是 585）。論文用詞 excursion 與實作不符。
控制循環時長後的偏秩相關由 +0.213 降至 **+0.150**，未消失。
換算至 SHE 約 −368 mV，落在文獻最適區間（−335.63 ± 28.97）內。
**→ 建議納入本次投稿：改用詞並加限定，約 8 mm。**

**二、甲烷化學計量對帳：三批全部通過硬上限 0.25。**
實測 0.2172 / 0.1682 / 0.1928。上限由 5 進 1 出決定，非擬合所得；
比值中頭空體積自動相消，故不需知悉該體積。
**首次獨立於壓力通道的驗證。→ 不進本篇**（n=3、峰值為目測、未經覆核）。

**三、十分鐘循環下估計器系統性失效。**
批次 3 逐段中位 **−0.031**（物理上不可能），14/14 全數通過曲率預篩。
資料集 C 排除清單裡的 0417-0427 亦為 10 分鐘循環、同樣症狀。
**→ 待洪博確認該條件下壓力是否提早趨於平衡，再決定是否寫入限制節。**

## 本日的兩次自我修正

1. 論文的 −3.7% 與投影片的 −2.1% 係**不同程序**（先取偏誤中位再修正
   vs 蒙地卡羅逐次修正再取中位），二者各自無誤。經討論**維持 −3.7%**
   （該值亦印於圖 4(b) 圖面），僅重排語序。
2. ORP 一項曾以 `dORP/Δt` 正規化得 +0.040 並判定「主要是循環長度」——
   該正規化係**對對數量做算術**，模型依賴，**已撤回**，
   回到免於變換的偏秩相關 +0.150。
