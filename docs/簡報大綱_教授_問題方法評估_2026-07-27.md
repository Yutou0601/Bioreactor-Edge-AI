# 第一部分：明確的問題

## S3. 背景——反應器與「可信訊號」
- 微正壓循環：進氣至 1.2 kg/cm² → 反應槽壓力隨二氧化碳被移除而下降 → 降到下限自動補氣 → 週而復始
- **可信訊號只有四個**：反應槽壓力、混合槽壓力、ORP、pH
- 二氧化碳／甲烷感測器有 ~99.98% 為無效拖尾，**僅供參考、不作證據**（重要前提，決定了方法選擇）
- 圖：fig1（標出補氣頂點、谷底、一次記錄中斷）

## S4. 明確的問題（Problem statement）★這頁最重要
- **主問題**：能否僅用可信的邊緣訊號（壓力／ORP／pH），**分離並量化**反應器內
  「二氧化碳物理溶解」與「生物產甲烷消耗」兩條途徑，並建立可即時運行的監測／預測？
- **為何非做不可**：甲烷產率（轉換效率）由生物消耗決定，但壓力只給你「總移除量」，
  物理溶解把生物訊號蓋住了
- **子問題**：
  1. 生物到底有沒有在作用、佔比多少？
  2. 哪個訊號最能反映生物活性？
  3. 什麼實驗設計才能把物理與生物拆開？
- **邊界**：不依賴不可信的二氧化碳／甲烷讀數即可回答

## S5. 為什麼這問題難——不可辨識性定理（★核心反證，含證明）
**模型（兩通道）**：頭空壓力 P(t)，物理溶解（質傳）＋生物消耗兩匯

$$\frac{dP}{dt} = \underbrace{-k_{La}\,(P - P_{eq})}_{\text{物理溶解}} \;-\; \underbrace{r_{bio}}_{\text{生物}}$$

- 生物項以 Monod 表示 $r_{bio}=r_{max}\dfrac{C_s}{K_s+C_s}$；高基質下飽和為零階 $r_{bio}\to r_b$（常數）

**定理（結構不可辨識）**：當 $r_{bio}\approx r_b$ 為常數，令 $P_{eq}' \equiv P_{eq}-\dfrac{r_b}{k_{La}}$，則

$$\frac{dP}{dt}=-k_{La}\big(P-P_{eq}'\big)\quad\Rightarrow\quad P(t)=P_{eq}'+(P_0-P_{eq}')\,e^{-k_{La}t}$$

- **可觀測軌跡只依賴 $(k_{La},P_{eq}')$，與 $(k_{La},P_{eq},r_b)$ 之分解無關。** 映射 $(k_{La},P_{eq},r_b)\!\to\!(k_{La},P_{eq}')$ 為多對一：對任意 $r_b$，取 $P_{eq}=P_{eq}'+r_b/k_{La}$ 得完全相同輸出 ∎
- ∴ $r_b$（生物份額）由 $P(t)$ **結構上不可辨識**——非資料不足，是模型結構使然
- 圖：**fig14 左panel①**（同一觀測曲線＝三組不同物理+生物分解完全重合，直觀證明）＋ fig8（六循環 $R^2\approx0.99$ 實測）

## S5b. 解方——循環時間使 $(P_{eq},r_b)$ 恢復可辨識（★數學依據）
- 關鍵：質傳係數隨循環時間變 $k_{La}=k_{La}(\tau)$，生物 $r_b$ 與 $\tau$ 無關
- 各循環時間 $\tau_i$ 觀測到「表觀平衡」$P_{eq}'(\tau_i)=P_{eq}-\dfrac{r_b}{k_{La}(\tau_i)}$，而指數率直接給出 $k_{La}(\tau_i)$
- 以 $P_{eq}'(\tau_i)$ 對 $1/k_{La}(\tau_i)$ 作圖為**直線**：

$$P_{eq}'=P_{eq}-r_b\cdot\frac{1}{k_{La}(\tau)}\quad\Rightarrow\quad \text{截距}=P_{eq},\;\; \text{斜率}=-\,r_b$$

- **兩個以上循環時間（1/5/10min）即可解出 $P_{eq}$ 與 $r_b$** → 分離成立。這是 5/10min 實驗的正式數學理由
- 圖：**fig14 右panel②**（$P_{eq}'$ 對 $1/k_{La}$ 直線，截距$=P_{eq}$、斜率$=-r_b$；1min 已收、5/10min 待收）

# 第二部分：所使用的方法

## S6. 方法總覽——四管齊下 + 兩條分離路徑（不是單一模型）
**核心是多訊號感測器融合**：壓力＝總移除、ORP＝氫氣消耗（生物專一）、pH＝二氧化碳消耗

| # | 方法 | 回答哪個子問題 | 嚴謹性來源 |
|---|---|---|---|
| A | 知識驅動灰箱／質傳模型 + profile likelihood 可辨識性 | 能不能分離 | 機理先驗、前沿標準法 |
| B | 多訊號生物探針（ORP＝氫氣、pH＝二氧化碳） | 哪個訊號反映生物 | 化學計量、去混淆 |
| C | 每循環共變數關聯（斜率 ↔ ORP／pH／補氣次數） | 生物有無獨立貢獻 | 叢集穩健標準誤 |
| D | **兩條分離路徑**：多訊號化學計量 + 循環時間 kLa 槓桿 | 如何把兩者拆開 | 感測器融合＋因子操縱 |

## S7. 方法 A——知識驅動灰箱模型 + profile likelihood
- 機理先驗，每個下降循環擬合 $P(t)=P_{eq}+(P_0-P_{eq})e^{-k_{La}t}$，抽出 $k_{La}$、$P_{eq}'$
- **為什麼不用黑箱 ML**：僅 6 循環，LSTM/XGBoost 學不動；機理讓問題塌縮成 2 個可解釋參數
- **Profile likelihood**（可辨識性判準）：固定待測參數 $\theta_i=c$、對其餘參數再最佳化

$$\text{PL}(\theta_i)=\min_{\theta_{j\neq i}}\; -2\log L(\theta)\big|_{\theta_i}$$

  曲線沿 $\theta_i$ 為**碗狀**（有限信賴區間）＝可辨識；**平坦**＝不可辨識（本研究 $r_b$ 即為平坦）
- 對照前沿：Raue et al. (2009, *Bioinformatics*)；生物甲烷化 knowledge-driven ML（*Chem. Eng. J.* 2026）
- 圖：fig8 + fig9（$k_{La}$、$P_{eq}$ 隨補氣次數）

## S8. 方法 B——多訊號生物探針（去物理混淆，含機理式）
- **ORP（氫氣探針，Nernst）**：$E_h = E^0 + \dfrac{RT}{nF}\ln\dfrac{[\text{ox}]}{[\text{H}_2]}$。氫氣為還原劑，消耗氫氣使 $[\text{H}_2]\!\downarrow$ → $E_h\!\uparrow$，故 **ORP 回升率 $\propto$ 氫氣消耗率 $\propto$ 生物活性**
- **pH（二氧化碳探針，碳酸平衡）**：$K_{a1}=\dfrac{[\text{H}^+][\text{HCO}_3^-]}{[\text{CO}_2]_{aq}}$，定鹼度下 $[\text{CO}_2]_{aq}\propto[\text{H}^+]=10^{-pH}$，故 $\dfrac{d[\text{CO}_2]}{[\text{CO}_2]}=-\ln 10\cdot dpH$（二氧化碳被消耗→pH 升）
- 化學計量 $\text{CO}_2 + 4\text{H}_2 \to \text{CH}_4 + 2\text{H}_2\text{O}$：氫氣用量 4×、為**限制反應物**，故 ORP 最靈敏
- 圖：fig10（左壓力、中 ORP 世代分層、右 pH 死平——緩衝壓制）

## S9. 方法 C——每循環共變數（混合／叢集穩健模型）
- 每次補氣＝一觀測；因補氣壓力固定，以下降斜率 $s_{ij}$ 對應該次 ORP、pH、補氣次數
- **模型**（$i$＝批次、$j$＝循環）：

$$s_{ij}=\beta_0+\beta_1\,\tau_i+\beta_2\,\text{ORP}^{pre}_{ij}+u_i+\varepsilon_{ij},\quad u_i\sim\mathcal N(0,\sigma_u^2)$$

- $\beta_1$＝循環時間（物理軸）、$\beta_2$＝菌群成熟度（生物軸）；**控制 $\tau$ 後 $\beta_2$ 是否顯著**即判生物有無獨立貢獻
- 同批多循環為偽重複 → **叢集穩健標準誤** $\widehat{\text{Var}}(\hat\beta)=(X^\top X)^{-1}\!\big(\sum_i X_i^\top \hat u_i\hat u_i^\top X_i\big)(X^\top X)^{-1}$；LOO 交叉驗證
- 圖：fig3（下降速率 vs 補氣次數 $r=-0.98$）

## S10. 方法 D——兩條互補的分離路徑
**路徑 1：多訊號化學計量（不必等循環時間）**
- 壓力給「總氣體移除率」$\dot n_{tot}$；ORP 給「氫氣移除率」$\dot n_{H_2}$（生物專一通道）
- 由 $\text{CO}_2:\text{H}_2=1:4$：生物二氧化碳消耗 $\approx \tfrac14\dot n_{H_2}$，物理溶解 $=\dot n_{tot}-$生物
- 代價：ORP→氫氣消耗率需 Nernst 校準（難點、future work）

**路徑 2：循環時間 kLa 槓桿（S5b 之數學）**
- 改 $k_{La}(\tau)$、生物 $r_b$ 不變 → $P_{eq}'(\tau)$ 對 $1/k_{La}$ 直線解出 $P_{eq}$、$r_b$
- 兩組對照決定性拆混淆：**換液對照**（重置二氧化碳飽和、不重置菌齡）、**無菌對照**（純物理基準，相減＝生物）
- 圖：fig14 右panel②（此頁放設計；5／10min 尚未收完，不放結果）

# 第三部分：如何評估優劣

## S11. 評估準則（怎麼判斷方法好不好）★教授要的第三軸
| 面向 | 指標 | 合格線／判讀 |
|---|---|---|
| 模型擬合 | $R^2$、LOO-CV RMSE | $R^2>0.98$ 且交叉驗證不崩 |
| **可辨識性** | profile likelihood 曲線形狀 | 碗狀＝可辨識；平＝不可（本研究穩態即為平） |
| 關聯顯著性 | **置換檢定 p** + 叢集穩健 SE | 小樣本不靠常態假設 |
| **分離度** | 物理份額 $\phi=1-\dfrac{r_{ss}}{r_{tr}}$（穩態率／暫態率） | 需暫態資料才可算 |
| 預測 | 壓力軌跡 RMSE、下次補氣時間誤差 | 邊緣端即時可算 |
| 落地 | 邊緣延遲、前端可用性 | Jetson 即時、不卡頓 |
- **置換檢定**（小 n 誠實顯著性）：$p_{perm}=\dfrac{1}{N}\sum_{\pi}\mathbb 1\!\big(|r_\pi|\ge|r_{obs}|\big)$
- **核心原則**：擬合好 $\neq$ 分離了；必須用可辨識性與對照才算證明

## S12. 目前進度（Progress，含誠實統計）
- **系統**：資料管線三缺陷修正（標籤格式解析器、記錄中斷門檻、下降段谷底判定）→ 既有實驗資料才真正能分析
- **分析**：1min 單批完成；六個乾淨循環；質傳 $R^2\approx0.99$
- **誠實統計（置換檢定）**：
  - 下降速率 vs 補氣次數 $r=-0.98$，$p_{perm}=0.003$（近 n=6 下限 0.0028）→ **物理減速：鐵證**
  - ORP 回升率 vs 補氣次數 $r=-0.88$，$p_{perm}=0.058$ → **生物訊號：暗示、尚未達顯著**（∴ 1min 不足以論證生物分離）
- **科學結論**：穩態下不可分離；甲烷 31.64% 依化學計量證明生物確在作用，課題是「能否分離量化」而非「有無」
- 圖：fig12（相關矩陣，全訊號同步減速）

## S13. 研究策略與論文骨架（先相關、後反證分離）
1. **相關（建設性）**：可觀測特徵帶結構——斜率、ORP、成熟度之關聯（fig3、fig10、fig12）
2. **反證（否證性）**：穩態 $\Rightarrow$ 結構不可辨識（S5 定理 + fig8 之 $R^2\!\approx\!0.99$ 視覺證據）
3. **解方（設計）**：循環時間 $k_{La}$ 槓桿 + 對照，恢復可辨識（S5b 之 $P_{eq}'$–$1/k_{La}$ 直線）
4. **分離（未來）**：以 5/10min + PINN/UDE 量化物理／生物份額 $\phi$
- **要點**：(2) 是最硬的貢獻——不可能定理可證、不可被質疑；1min 即足以支撐 (1)(2)(3)

## S14. 前沿算法對位（查證後）
- **結構可辨識性工具**（SIAN、StructuralIdentifiability.jl、DAISY）：把 S5 手證升級為**形式化定理**——1min 即可做
- **Physics-informed Neural ODE / UDE**：動態拆成「已知物理項 + NN 殘差項」，讓 NN 學生物殘差；**需多條件（5/10min）暫態資料** [JSV 2021；arXiv 2412.08681]
- **PINN 於厭氧消化甲烷預測**：Modified Gompertz，$R^2\!\approx\!0.99$（MDPI Water 2025）——同領域預測基準
- **Profile likelihood 實務可辨識性**（Raue 2009）：已用於灰箱
- **判斷**：**不對 6 循環再加黑箱算法（fishing）**；瓶頸是資料非算法，正向分離待 5/10min

## S15. 下一步與風險
- 收 5／10min 批次 → 啟動循環時間（物理軸）× ORP（生物軸）雙軸分離
- 加換液／無菌對照 → 決定性拆「菌群老化 vs 二氧化碳飽和」
- 風險：循環時間與菌齡共線（需穿插順序或補收 1min 檢查漂移）
- 落地：把 ORP 回升率、$k_{La}$/$P_{eq}$ 做成前端即時指標

## S16. 結語（一句話賣點）
- 本平台在**只有壓力／ORP／pH 可信**的嚴苛條件下，用**知識驅動 + 多訊號 + 因子操縱**的組合，
  把「物理 vs 生物」由**可證的不可辨識**推向**可設計的可辨識**；方法嚴謹、有數學證明、可即時運行於邊緣，評估準則明確。
