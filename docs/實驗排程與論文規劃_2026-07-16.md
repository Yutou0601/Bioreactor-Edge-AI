日期：2026-07-16

## 1. 正式實驗設計表（Design of Experiments）

給洪博看的版本，用標準 DOE 格式表達，方便他直接確認或提出修改。

### 1.1 固定變量（Fixed / Controlled Variables）

| 變量 | 設定值 | 備註 |
|---|---|---|
| 進氣氣體比例 | H2 : CO2 = 4 : 1 | 依反應計量比固定，跟舊「循環」資料的 1:1 批次是不同設定，不混用 |
| 進氣壓力目標 | 至 1.2 kg/cm² | 沿用使用者先前提給洪博的協定版本 |
| 排氣壓力目標 | 至 0.95～1.0 kg/cm² | 同上 |
| 溫度 | 盡量控制在單一窄範圍內，全程記錄 | pH-溶解量關係理論上受溫度影響（碳酸鹽緩衝平衡），溫度波動大會混淆分析 |
| 感測頻率 | 每分鐘 1 筆（ORP／壓力／pH／溫度） | 現有系統既定規格 |

### 1.2 操縱變量（Manipulated Variable）

| 變量 | 水準（Levels） | 每個水準重複次數 |
|---|---|---|
| 循環觀察窗口 n（分鐘） | 1、5、10、20 | 至少 6～8 次，不同天、不同起始 pH/壓力條件下各測 |
| 循環起始所屬 ORP 相位 | Phase 1／2／3（依動態閾值判定） | 同一個 n 值盡量涵蓋不同相位各測幾次 |

→ 最少需要 4（n值）× 6（重複）＝ **24 次循環**，若要涵蓋相位交叉最好到 30~40 次。

### 1.3 應變變量（Response Variables）

| 變量 | 量測方式 |
|---|---|
| 排氣時 CO2%／CH4% 讀數（含穩定後數值） | 排氣後持續記錄到讀數平坦為止，不是排完就停 |
| 循環期間 ORP／壓力／pH 逐分鐘軌跡 | 既有系統自動記錄 |

### 1.4 需要洪博確認/拍板的項目

- [ ] 排氣後能否持續監測到讀數穩定（可能長達 1~2 小時），現場排氣流程是否允許拉長？
- [ ] 是否有生物活性極低的階段（換液初期／菌群未適應）可以當物理溶解的對照組？
- [ ] n=20 分鐘這組會不會跟既有「循環」定義（每小時循環幾分鐘）的排程衝突？
- [ ] 自動排氣機能能否用在這個協定（可大幅降低人工計時誤差）？
- [ ] **設備可連續使用的時間窗口有多長**（決定下方時程能不能排得下）？

（前四項已列在 `docs/實驗設計_短窗口CO2分離協定_2026-07-16.md`，這裡合併列出方便一次確認）

## 2. 時程規劃（往回推算，46 天）

實驗執行所需天數目前無法精確估計（取決於洪博確認的設備可用時間窗口），下表先抓合理區間，
**設備排程確認後要回頭調整**。論文前三頁（Intro／Background／Methodology）不依賴實驗結果，
可以現在就開始寫，這樣後面時間全部留給跑實驗、跑分析、寫結果，不會卡在最後兩週趕工。

| 週次 | 日期區間 | 任務 | 依賴 |
|---|---|---|---|
| W1 | 07/16 ~ 07/20 | 跟洪博確認 DOE 表 + 設備時間窗口；開始寫論文前 3 頁 | 本文件 |
| W2 | 07/21 ~ 07/27 | 先跑 2~3 次 pilot 循環（驗證排氣讀數穩定的等待時間、log 格式跑得動）；論文前 3 頁繼續寫 | 洪博拍板結果 |
| W3~W4 | 07/28 ~ 08/10 | 正式收集 24~40 次循環資料 | pilot 結果沒問題 |
| W5 | 08/11 ~ 08/17 | 跑 `co2_moga_calibration.py` 分析、整理結果 | 實驗資料到位 |
| W6 | 08/18 ~ 08/24 | 寫論文結果／討論／結論，整理圖表 | 分析完成 |
| W7 | 08/25 ~ 08/31 | 校稿、留緩衝、投稿 | — |

**風險點**：W3~W4 只有 2 週，如果每次循環（含排氣穩定等待）要花 2~3 小時，24~40 次循環實際
需要的「設備佔用天數」要看能不能連續跑（例如一天排好幾次 vs 一天只能排一次），這點務必第一
優先跟洪博確認，直接決定這份時程可不可行、要不要縮減重複次數或 n 值組數。

## 3. 論文前 3 頁大綱（現在就能寫，不用等實驗結果）

4-6 頁篇幅（ICEA 官方 CFP），抓前 3 頁為「不依賴數據」的部分：

**Page 1：Title / Abstract / Introduction**
- 研究動機：氫氣甲烷菌在壓力下的氣體使用量預測，延伸自舊研究（ORP 相位偵測 + GA/Ridge 預測 CH4 峰值）
- 問題定義：壓力下降同時反映「CO2 物理溶解」與「被生物消耗」兩個機制，兩者同時發生、無法用簡單質量守恆分離

**Page 2：Background / Related Work / Problem Formulation**
- 舊研究成果簡述（ORP EMA/S-G 濾波、自適應相位偵測、GA+Ridge CH4 峰值預測 RMSE 3.13%）
- 文獻佐證：AHPD 中 pH 隨壓力上升下降（CO2 過量溶解）、H2 添加後 pH 因 CO2 消耗而上升、H2 低溶解度是氣液傳質瓶頸（今天查到的三篇文獻可直接引用）
- 問題定義：為什麼 CO2%/CH4% 感測器數據不可靠（分析儀延遲拖尾、人工排氣時機、產出緩慢），為什麼這是欠定問題（沒有唯一解）

**Page 3：Methodology**
- 實驗協定（DOE 表，本文件第 1 節）
- 機制假設（pH → 溶解、壓力守恆式、ORP 獨立交叉驗證）
- NSGA-II 多目標啟發式演算法設計（決策變數、兩個目標函數、為什麼不能用線性迴歸/CH4 當標籤）

Page 4 之後（結果、討論、結論）等實驗資料進來、`co2_moga_calibration.py` 跑出結果後再寫。
