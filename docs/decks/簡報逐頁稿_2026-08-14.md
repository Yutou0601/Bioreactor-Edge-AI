# 第 3 頁　研究設備：階梯式分壓

**放 Fig 1（`figE_pressure_cascade`）**

```
3L H₂  ─V2─┐                              ┌─→ 光學分析儀 CH₄
           ├→ 混合槽 1L, 4:1 ─V3→ 5L 反應槽 ┤
3L CO₂ ─V1─┘                    PT ↑  循環泵 └─→ 光學分析儀 CO₂

反應物系統 ≤6      反應菌系統 ≤1.5      生成物系統 ≤1   kg/cm²
```

- 氫氣與二氧化碳以 **4:1** 預混（CO₂ + 4H₂ → CH₄ + 2H₂O 的化學計量比）
- 由高至低三層降壓，菌液維持微正壓、下游分析儀接近常壓
- 循環泵將頭空氣體自槽底以氣泡送回——這是維持氣體持續溶解的機制
- **PT 是本文唯一使用的通道**；開啟 V3 的控制器是封閉單元，狀態不被記錄

# 第 5 頁　問題：兩條途徑，一個通道

封閉頭空的壓力下降同時來自兩件事：

- **生物**：甲烷化每產生 1 莫耳氣體消耗 5 莫耳 → 壓力降
- **物理**：新注入的 CO₂ 溶解 → 壓力也降

領域慣常的解法是**加第二個物理通道**（例如壓力式生物甲烷潛勢法量瓶重），
但本設備不允許加裝、也不允許對生產中的槽體施加激發。

> 核心問題：**能不能只用一個量化壓力通道，把生物速率讀出來？**

**放 Fig 2(a) 四日壓力軌跡**——鋸齒即觸發迴路的特徵，每一段下降側就是一次弛豫實驗。

# 第 6 頁　困難：兩項可以互換

把下降寫成

$$P(t) = P_{eq} + A e^{-kt} - r_b t \tag{1}$$

- 指數項 = 趨近平衡的物理過程
- 線性項 = 定速率的生物移除

當觀測窗內 $kT$ 很小，$e^{-kt} \approx 1 - kt$，**兩項就可以互換**。

實測後果：**兩組 $r_b$ 相差 2.5 倍的擬合，殘差平方和落在彼此的 1% 之內。**

這不是實作缺陷，是指數擬合自 Lanczos 以來即被理解的性質；以 Gutenkunst 的
語彙，模型沿著「以 A 與 k 交換 r_b」的方向是**鬆散的**（sloppy）。

# 第 7 頁　方法總覽

**放 Fig 2(b) 探勘管線**

```
切分 → 篩選 (Alg.1) → 擬合 (式1) → 配對校準 (Alg.2) → 參照分布 (Alg.3)
280 循環  →  篩選後保留 239  →  中位 r_b = 0.0128 → 修正後 0.0126
```

三個演算法，各自回答一個問題：

| | 目的 |
|---|---|
| **Algorithm 1** Extracting a Trustworthy Rate from One Cycle | 這個循環算不算得出可信的速率？ |
| **Algorithm 2** Measuring and Removing the Degeneracy Bias | 估計器本身扭曲了多少？ |
| **Algorithm 3** Ruling Out a Purely Physical Explanation | 純物理能不能產生這個成分？ |

# 第 8 頁　Algorithm 1：擬合前先篩選

**為什麼要在擬合之前**：輪廓概似能診斷這個簡併，但它是**從**一個擬合結果算出來的，
而在這份資料上，擬合結果正是我們還不信任的東西。

篩選統計量 = 正規化中點曲率

$$c = \frac{y(0) - y(T/2)}{y(0) - y(T)} \tag{2}$$

- 完全筆直的下降 → **恰為 0.5**（此時式 1 的兩項無法區分）
- 軌跡愈彎 → 值愈大
- 門檻 **c\* = 0.45**，由**已知真值的合成循環**回收表現固定，**不是在實測資料上挑的**
- 低於該值時回收中位數偏誤超過 25%

**281 → 239 個循環通過**。演算法僅用 NumPy，符合監控電腦 60 MB 預算。

---

# 第 9 頁　相關係數 0.814 不能直接讀

擬合出的 $\hat r_b$ 與 $\hat k$ 相關 **ρ = 0.814**。

照字面讀，這像是「估計值是假影」的證明。**但它單獨無法解讀**——
兩者共同吸收同一段下降，**即使真值固定也會相關**。

> 真正的問題是：這個相關**超出**固定真值本身已經產生的程度多少？

**做法**：以 Schuemie 等人的經驗校準，把理論虛無 ρ = 0 換成
「由已知真值的案例估得的虛無」。

---

# 第 10 頁　Algorithm 2：設計配對校準

每個真實循環貢獻**它自己**擬合所得的參數：

```
k̂ᵢ,  Âᵢ,  P̂eq,ᵢ,  時長,  殘差尺度,  AR(1) 係數
```

**只替換真實的 r_b**，其餘完全沿用，再通過完全相同的流程。

> 估計器的扭曲同時出現在比較的兩側，因而互相抵消——這是間接推論的邏輯。

**與 Schuemie 的差別**：他們的負對照是「被認為屬虛無」的觀察案例；
我們的是沿用真實設計的模擬，因此能把真值**精確固定**而非加以假設。

---

# 第 11 頁　★ 恆定真值被排除

**放 Fig 3(a)**

不假設 k 依賴的形式，改把它的**強度**當成待反解的量：

$$r_b(k) = r_b^{0} \left(\frac{k}{k_{med}}\right)^{\beta}$$

採冪次形式的兩個理由：**r_b 恆正**（避免非物理的負值）；**中位真值對每個 β 都等於 r_b⁰**（不同 β 才可比）。

| β | ρ |
|---|---|
| **0（恆定真值）** | **0.304 ± 0.056** |
| 0.30 | 0.707 |
| 0.80 | 0.747 |
| **實測** | **0.814** |

★ 恆定真值只給 0.304，與實測相差**約九個標準差** → **排除**
★ 只讓 r_b 有變異卻不與 k 掛勾，相關反而降到 0.143
★ β ∈ [0.20, 0.80] 可在校準散布內重現實測 → 這是**相容集合**

# 第 12 頁　偏誤分解：兩件事不可混為一談

**放 Fig 3(b)**

| | 大小 | 性質 |
|---|---|---|
| **篩選的選擇效應** | 隨 β 升到 **37%** | **不是誤差，是定義** |
| **估計器自身扭曲** | −4.1% ~ +5.8% | **這才是要修的** |

**為什麼選擇效應不修**：
篩選以曲率收循環，它留下的真值本來就不是全母體的真值。但我們報的是
「**在可辨識的循環上**」的速率，而篩選正是使它們可辨識的東西。

# 第 14 頁　Algorithm 3：排除純物理的解釋

**做法**：對每個保留循環先擬合 $P(t) = P_{eq} + A e^{-kt}$（即式 1 中 r_b 強制為零），
使虛無重現該循環**自己的**平衡值、振幅與鬆弛常數；再由該擬合重新生成、
加 AR(1) 雜訊、量化到 0.01、通過**完全相同**的篩選與估計器。

**結果**

| | 值 |
|---|---|
| 純物理虛無下的聚合中位 | +0.00008 ± 0.00010 |
| 實測 | **0.0128** |
| 置換檢定 | **p = 0.024** |

虛無比實測低**兩個數量級**。

> ⚠ 推論的**方向**要講清楚：它**排除純物理的解釋**；
> 它本身**並未**確立殘餘成分即為生物性。

# 第 15 頁　端點選擇偏誤：已排除

切分讓每個循環結束於補氣前最後一個取樣點，而該點之所以被選中，
**正是因為**壓力下降到足以觸發 → 它位於底層趨勢之下。

疊加殘差：末點平均為循環振幅的 **−0.068**，其餘位置 ±0.006。
線性斜率在端點最敏感，這是一條合理的高估途徑。

**裁切檢定**：移除每個循環最後 5 至 90 分鐘

- 中位 r_b 只在 **0.0124–0.0133** 之間移動（±5%）
- 無觸發選擇的設計配對模擬**漂移幅度相當**
- 約 620 個取樣點中的一個異常點，槓桿不足以扳動斜率

→ **速率不是切分位置造成的假影**

# 第 16 頁　★ ORP 獨立佐證

前面全部由壓力導出。通過純物理參照說的是**它不可能是什麼**，不是**它是什麼**。

**ORP 完全不進估計，而且它不是速率**——它反映溶解氫的還原能力，
指的是菌群多**活躍**，不是氣體消失多**快**。正因為不在模型裡，才能當檢查。

按每個循環的氧化還原擺幅排序，比較三分位的聚合速率：

| ORP 活躍度 | 聚合 r_b |
|---|---|
| 最低三分之一 | 0.0099 |
| 中間三分之一 | 0.0134 |
| **最高三分之一** | **0.0152** |

跨度 **54%**，拔靴區間 [0.0004, 0.0137] **不含零**。

> 一個在**不同物理通道**（液相而非氣相）測得的量，把壓力軌跡給出的速率
> **排出同樣的順序**——這是單靠壓力給不出來的。

**必須同時講的界線**：排序是聚合的、不是逐循環；ORP 同時受 pH 與溶解 CO₂
影響，不是氫氣計；沒有成分錨點就無法換算成速率。

# 第 17 頁　模擬器充分性

配對基準若建立在不像真的模擬器上，就毫無意義。以**分類器雙樣本檢定**驗證
（Friedman 提出、Lopez-Paz & Oquab 重訪、Dalmasso 等人用於驗模擬器）。

| 雜訊模型 | AUC |
|---|---|
| 白高斯 | 0.968 |
| AR(1) | 0.832 |
| **AR(1) × 1.3φ̂（校準後）** | **0.695** |

- 實測殘差的 lag-1 自相關中位 **0.266**——不是白雜訊
- 校準後十項邊際特徵全部吻合到 **0.29 個合併標準差**之內
- 最大差距為單調比例（0.808 對 0.786）

> ⚠ **不宣稱模擬器已充分**：殘餘 AUC 0.695 表示仍可區分，
> 不吻合處位於我們尚未辨識出的**聯合結構**。

# 第 18 頁　三項限制

**① 逐循環不可用**
聚合中位數可回復，但個別值散布極廣且與 k̂ 耦合。
本文任何內容都不足以支持把單一循環讀作一次速率量測。
ORP 檢查同樣是聚合層次的。

**② 模擬器仍可被區分**（AUC 0.695）
配對基準因此只是近似。我們**不**在此模擬器上做模擬式推論——
由設定錯誤的模擬器學到的後驗會是又窄又錯，而不只是不確定。

**③ 部署預算 60 MB**
瓶頸是**函式庫體積**而非演算法成本：NumPy 單獨 27 MB，完整科學堆疊 129 MB。
整條流程僅以 NumPy 撰寫。這也是未採用學習式模型的原因——
困難在可辨識性而非函數逼近，額外參數只會以更低的可見度吸收同一個簡併。
